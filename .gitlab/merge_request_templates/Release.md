## 체크
- [ ] 소스가 `dev`, 대상이 `main`인지 확인했습니다.
- [ ] 포함 기능과 통합 검증 결과를 기록했습니다.
- [ ] 검증 이후 추가된 변경이 있다면 다시 검증했습니다.
- [ ] 운영 후보가 검증한 코드·이미지·설정과 일치합니다.
- [ ] 연관된 기존 구현·설정과 운영 문서·예제가 릴리스 버전과 일치합니다.
- [ ] 공통 API 변경의 기존·신규 버전 호환성과 서비스 적용 순서를 확인했습니다.
- [ ] 설정과 DB 변경, 적용 순서, 롤백 방법을 확인했습니다.
- [ ] 이전 앱의 DB 호환성과 격리 DB 복원 결과를 기록했습니다.
- [ ] main 병합 후 자동 배포에 필요한 운영 설정·DB 준비를 완료했습니다.
- [ ] Squash commits를 해제했습니다.
