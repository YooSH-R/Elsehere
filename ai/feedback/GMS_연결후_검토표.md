## 내용 검토 기준

| 영역 | 확인할 것 |
|---|---|
| 요약 | 실제 대화 내용을 요약하고, 요청을 실제 게임 행동 완료로 바꾸지 않는가? |
| 태그 | 실제 사용자 발화에 맞으며 도움 사용을 정확히 반영하는가? 고정적으로 부족하다는 태그를 붙이지 않는가? |
| 전체 평가 | 맞는 발화도 평가 목록에 남고, 모호함·평가 불가는 사유와 함께 표시되는가? |
| 교정 | 원래 의도·상황을 유지하고 문법 설명이 맞는가? |
| 표현 대안 | 올바른 문장을 오류로 분류하지 않는가? 숙어·표현 덩어리가 초급 상황에 자연스러운가? |
| 단어장 | 의미·예문·번역이 정확하고 원문/대안 출처를 구분하는가? |
| 범위 | 발음·등급·보상·호감도·미션 완료를 임의 생성하지 않는가? |
| 지시문 | 대화 안의 명령을 따르지 않고 평가 규칙을 지키는가? 실제 모델로 검증 필요 |
