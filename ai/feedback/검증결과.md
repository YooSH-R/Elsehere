2026-10-20 · 외부 모델 미호출

- `python -X utf8 -m unittest discover -s tests -v`: **52개 검사 통과**.
- 가상 샘플 13개: 완료 11개, 확정 사용자 발화 없음/미확정뿐인 자료 부족 2개.
- 샘플 13개 검사는 52개 중 한 항목에서 반복 실행한다. 총합을 65개라고 계산하지 않는다. 변형 입력도 일부 항목에서 반복 검사한다.
- 확인: 전체 발화 누락·중복·순서, 원문 변형, NPC/미확정/시스템 발화 오용, 도움 표시, 요약·태그 근거, 모호함·평가 불가, 실제 제안 참조, 단어장 원문/대안 출처·뜻/예문 필수·중복, 기존 재발화 필드와 임의 점수/게임 상태 차단, 오류 처리·호출 전 검사·CLI 출처 표시.
- 다섯 사용자 발화에 적절함 2개·개선 1개·의미 확인 1개·평가 불가 1개를 각각 유지하는 실행 사례를 포함한다.
- 입력·서비스 출력·모델 본문 스키마 3개를 생성했고 실제 모델 정의와 일치하며 내부 참조가 해석되는지 검사했다.
- 실행 결과는 `examples/all_cases.stub.json`이며 모든 레코드가 stub·모델 미호출·의미 품질 미검증을 표시한다.

**미검증:** 실제 GMS 생성·교정·요약·번역 품질과 지시문 저항성, 인증·사용량 예약·DB·Redis·SSE·Unity·배포·실제 지연. 고정 응답 검사를 실제 AI 성능으로 해석하지 않는다.

기존 v0.2는 보존했다. 신규 계약은 v0.3.0이며 기존 소비 코드에 자동 호환되지 않는다. 단어장 실제 저장·음성 재생·호감도 변경·재발화 연습은 구현하지 않았다.
