# 3D AI 언어학습 서비스 — MVP 기능 범위

> 2026.10.19 · 팀 공유 및 범위 검토용 · 세부 기능명세·개발 담당 미확정

**목표:** 처음 서비스를 이용하는 사용자가 초기 설정과 튜토리얼을 거쳐 3D 마을에서 NPC와 AI 자유 대화를 하고, 대화 후 피드백을 확인하는 흐름을 구현한다.

## 1. MVP 사용자 흐름 (첫 접속 기준)

1. **사이트 접속**
2. **회원가입/로그인**
3. **사용자 정보 입력 및 초기 설정** — 배우고 싶은 언어 선택, 레벨 테스트, NPC AI 난이도 설정
4. **서비스 튜토리얼**
   1. 방에서 시작
   2. 서비스 설명
   3. 키조작 설명
   4. 마우스 호버 이벤트 설명 — 집 안의 가구들을 호버해보면서 학습
   5. 미션 시스템 설명 — 밖으로 나가 길 잃은 사람을 도와주는 미션 제공
   6. 사용자가 집 밖으로 나가면 **행인 NPC가 사용자에게 다가와 먼저 말을 걸기**. 사용자는 대화를 진행할지 말지 선택
   7. 대화 진행 — 행인 NPC가 카페가 어디에 있는지 물어봄. 사용자 화면에 길 안내 관련 추천 단어와 문장을 표시하고, 대화 UI의 기능을 설명. **튜토리얼 대화는 자유도가 낮은 정해진 흐름**으로 진행
   8. 대화가 끝나면 AI 피드백 및 단어장 설명
   9. 길 안내를 완료하면 튜토리얼 종료
5. **새로운 미션 2~3개 제공** — 카페 NPC나 숙소 NPC를 만나도록 유도
6. **시설로 이동**
7. **NPC 상호작용**
8. **NPC AI 자유 대화** — 튜토리얼과 달리 자유로운 대화 진행
9. **대화 종료 후 짧은 피드백** — 상세보기를 누르면 상세 피드백 확인

## 2. MVP에 포함되는 공통 기능

| 구분 | 핵심 범위 |
|---|---|
| 3D 환경·상호작용 | Unity 기반 PC 웹, 기본 이동·카메라, 방/마을/시설 탐색, 사물 호버, NPC 대화 진입·종료 |
| 대화·AI | 튜토리얼 안내형 대화와 일반 NPC 자유 대화, STT·LLM·TTS, 사용자 난이도 반영, 대화 보조(추천 표현·힌트·뜻 보기) |
| 학습 | 대화 후 짧은·상세 피드백, 단어장, 복습 기능 |
| 사용자·운영 | 회원가입/로그인, 초기 설정 및 튜토리얼·학습 상태 저장, AI 사용량 제한, 오류 시 정상 복귀, AI 소진 후 비AI 기능 이용 |

## 3. MVP 이후 개발 범위

- NPC 장기 기억·친밀도, 고도화된 NPC 생활 행동
- 일일 퀘스트·복잡한 사건/연결 사건 및 보상 시스템
- 콘텐츠·학습 고도화, 정밀 발음 평가, 모바일 웹, 결제·크레딧 충전

**범위 메모:** 본 문서는 MVP의 큰 사용자 흐름과 기능 범위만 정리한다. 시설·NPC 수, 튜토리얼 미션 거절 시 처리, 레벨 테스트 방식, 복습 세부 규칙 등은 후속 기능명세에서 결정한다. 기존 03·04 문서의 W1/W3 구분과 달라지는 내용은 팀 합의 후 갱신한다.
