## 변경 사항(v2.0 → v2.1)

- **유료 AI 사용량 0에서도 게임이 끝나지 않음**: 3D 탐험, 호버, 단어장, 복습, 기존 기록·피드백, 적법하게 저장된 오디오 재생은 지속.
- **유료 새 호출만 서버 사전 차단**: 새로운 NPC 자유 응답, STT·TTS, 동적 번역·힌트·AI 평가 등.
- **기존 세계 상태 유지**: NPC 장기 기억·친밀도·퀘스트 진행은 보존, AI 의존 퀘스트만 일시 대기.
- 화면에 한도 소진 이유와 계속 이용 가능한 활동 안내; 대화 중 소진해도 정상 종료/탐험 복귀.
- 무료 AI 지급량·갱신 주기·추가 충전 방식·유료 결제·퀴즈 보상 크레딧은 여전히 **미확정**이며, 개발 AI가 임의로 수치나 결제 시스템을 고정하지 않음.

## 근거와 주의

프로젝트 내 사용자의 기존 AI 비용 제한/무료 활동 유지 논의와 현 v2.0 문서를 기준으로 보완. 사용자가 제시한 ChatGPT 공유 링크는 이 환경에서 원문 본문을 직접 가져오지 못했으므로, 링크에만 있는 추가 정책은 반영 여부를 확정하지 않았습니다. 필요하면 해당 대화의 원문을 전달받아 추후 보완할 수 있습니다.

AI 코딩 에이전트에는 **03_AI용_제품기획안.md와 04_AI용_요구사항명세서.md를 동시에 제공**하고, REQ-20·29·30을 초기에 통합 검증하도록 합니다.
