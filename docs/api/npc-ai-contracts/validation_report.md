로컬 파일·JSON Schema·참조·예시·계약 규칙 검증. HTTP/DB/LLM/TTS 통합 테스트가 아님.

## 포함한 검사

공통 정의와 OpenAPI 내부 JSON 스키마 문법, 내부/외부 참조 연결, 설정·요청·응답·오류 예시, 선택값 생략, 구형 프로필 거부, 버전·길이·enum·중복 ID·대화 유형 조건, 요청–응답 식별자, 문서 JSON 예제와 파일 링크를 검사했다.

## 포함하지 않은 검사

OpenAPI 전체 문서에 대한 별도 OAS 전용 검증기 인증, 실제 서버의 HTTP 상태·인증·취소 처리, DB 트랜잭션·참조 존재·프로필 스냅샷, 모델 응답 품질·인격 다양성, TTS 생성·재생, 실측 지연·비용은 검사하지 않았다. 선택한 스키마/예제 검사 통과를 서버 구현 완료로 해석하지 않는다.

## 재실행

```bash
python -m pip install -r requirements.txt
python validate_contracts.py
```

상세 사례는 `validation_results.json`을 참조한다. 검사 수에는 스키마·참조·문서 링크 검사도 포함된다.
