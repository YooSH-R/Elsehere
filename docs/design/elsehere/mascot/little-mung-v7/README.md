# 리틀 멍 v7 캐릭터 기준

현재 캐릭터 작업 기준은 **리틀 멍 v7**이다. v4 B의 대두 비율과 모인 얼굴 배치를 바탕으로, 눈동자를 더 둥글게 표현하고 중앙 이동 전 B의 눈동자 위치를 복원한 디자인이다. 가장 최근 제작한 정면·양쪽 측면·후면 4장을 v7의 기준 이미지로 사용한다. `tripo-turnaround-v1`의 v1은 4방향 입력 묶음의 버전이며 캐릭터 디자인 버전 v7과 구분한다. 마을 기준은 별도로 브릭 메인스트리트 v3-B를 유지한다.

## 현재 버전의 디자인 기준

- **분위기와 비율:** 예쁘고 귀여우면서 살짝 멍한 표정의 미니어처 3D 캐릭터. 아주 큰 머리와 작은 몸, 짧은 팔·다리를 유지한다. 머리 약 60%·턱 아래 몸 약 40%는 제작 검증 시작값이며 이미지에서 확정된 실제 모델 치수가 아니다.
- **얼굴 배치:** v4 B/Cluster의 얼굴 중앙에 모인 눈·코·입과 양쪽 볼의 넓은 여백을 유지한다. 흰자 사이의 간격과 검은 눈동자 위치를 별개로 관리한다.
- **눈동자 위치:** 중앙 이동 전 B처럼 각 눈의 검은 눈동자가 코 쪽에 조금 붙는다. 화면 왼쪽 눈동자는 흰자 안에서 오른쪽, 화면 오른쪽 눈동자는 왼쪽에 놓인다. 흰자의 바깥쪽 여백이 코 쪽보다 넓다. 흰자 중앙으로 옮기거나 좌우 여백을 같게 맞추지 않는다.
- **눈·코·입 표현:** 최근 수정한 둥근 느낌의 검은 눈동자와 작은 하이라이트·속눈썹을 유지한다. 완전한 기하학적 원을 뜻하지 않는다. 코는 작고 얄쌍하게, 입은 작고 부드러운 미소로 표현한다. 표정과 시선 애니메이션은 이 기본 인상을 출발점으로 별도 제작한다.
- **현재 대표 외형:** 코코아색의 둥근 단발과 덩어리감 있는 앞머리, 연보라 재킷·아이보리 티셔츠·민트 반바지·크림색 운동화. 부드러운 입체감과 무광에 가까운 재질을 사용한다. 이 외형은 여성 플레이어 대표이며 모든 NPC의 헤어·복장을 동일하게 고정하는 뜻은 아니다.
- **후속 제작:** 새로운 수정은 현재 정면 이미지에서 시작하고 측·후면과 함께 대조한다. 남녀 플레이어와 NPC는 이 비율·표현 방식을 공유하되 피부색·헤어·얼굴 인상·의상으로 구분한다. 기존 A안, 넓어진 얼굴 배치, 중앙 이동한 눈동자 시안으로 되돌아가지 않는다.

현재 버전의 고정은 **시각 디자인과 입력 이미지의 기준 지정**이다. 실제 Tripo 메시, 공통 리그, 모듈 교체, 립싱크 또는 Unity 성능의 검증 완료를 의미하지 않는다.

눈동자 위치는 **중앙 이동 전 `roster-ab-v1.png`의 아래 두 줄 B**를 기준으로 한다. 화면 왼쪽 눈의 검은 눈동자는 흰자 안에서 오른쪽, 화면 오른쪽 눈의 눈동자는 왼쪽에 놓여 각각 코 쪽에 조금 붙는다. 코 쪽 흰자 여백이 바깥쪽보다 좁은 원래 시선을 유지한다. 눈동자 모양을 둥글게 바꾸더라도 중심 위치를 흰자 중앙으로 옮기지 않는다.

v2 이미지는 이 시선을 다시 반영해 현재 4방향 이미지를 만들 때 사용한 입력이다. 현재 결과와 이 입력은 픽셀 단위로 동일한 편집이 아니며, 눈동자도 완전한 기하학적 원으로 검증한 것은 아니다.

눈동자를 흰자 중앙으로 옮긴 시안과 B라는 이름으로 생성됐지만 눈 간격이 넓어진 시안은 채택하지 않는다. `roster-ab-v2.png`, `roster-b-centered-*`, `roster-b-review-v3.png`, `b-round-pupils-master-v1.png`, 중앙 이동용 프롬프트·스크립트·검증 결과는 보관용이며 제작·시선 애니메이션의 기준으로 사용하지 않는다.

| 항목 | 제작 시작값 |
| --- | --- |
| 전체 높이 | 1.60m 확정 |
| 기본 헤어 최고점부터 턱까지 | 약 0.96m, 전체의 60% |
| 턱 아래부터 신발 바닥까지 | 약 0.64m, 전체의 40% |
| 머리와 턱 아래 몸의 높이 비 | 약 1.5:1 |

비율의 기준점은 기본 헤어 최고점·턱 아래·신발 바닥이다. 전체 키 1.6m는 확정된 제작 기준이다. 머리·몸 배분은 원본 이미지의 인상을 제작용으로 근사한 시작값이며 실제 모델 측정값이 아니다. 플레이어와 모든 NPC가 같은 비율·관절 기준을 사용하도록 검증한다.

생성 프롬프트는 실제 사용한 원문을 보존한다. 원문 속 `v4 B`는 당시의 이름이며, 해당 프롬프트로 생성한 네 이미지의 현재 관리 버전은 v7이다. 후속 생성은 v7 정면 이미지를 입력으로 사용한다.

측면 파일명은 캐릭터의 코가 이미지의 어느 쪽을 향하는지를 뜻한다. 업로드 화면의 좌·우 지정 방식에 맞춰 이미지를 확인한다. 정면의 눈동자는 중앙 이동 전 B의 코 쪽에 조금 붙은 위치를 유지할 기준이다.

옆·뒤 두상, 단발머리의 뒷부분과 재킷의 등판은 정면에서 추정한 디자인이다. 네 이미지는 같은 3D 메시를 회전해 렌더한 결과가 아니므로 정확한 90도 투영이나 시점 사이 기하학적 일치를 보증하지 않는다. 실제 모델에서 두상 깊이, 헤어 끝선, 목·어깨 연결, 의상 길이, 손·발과 눈동자 위치를 확인한다. 이 묶음의 준비만으로 Tripo 모델 생성·리깅·Unity 검증이 완료된 것은 아니다.

## 얼굴 배치와 시선 기준

선택된 B는 눈 전체·눈썹·코·입이 얼굴 중앙에 모여 있고 양쪽 볼에 여백이 넓은 배치다. 흰자 사이의 간격과 흰자 안에서의 검은 눈동자 위치를 별도로 유지한다. 흰자 간격이 비슷하다는 이유만으로 시선까지 보존됐다고 판단하지 않는다. A처럼 눈 전체를 양옆으로 벌리지 않는다.

**현재 정면은 중앙 이동 전 B 시트의 코 쪽에 조금 붙은 눈동자 배치를 이어받는다.** 흰자 양옆의 여백을 맞추기 위해 눈동자를 중앙으로 강제 이동하지 않는다. 현재의 둥근 눈동자 표현, 눈 전체의 크기·간격, 눈꺼풀·속눈썹, 코·입의 위치를 함께 유지한다. 실제 중립 시선과 시선 애니메이션은 3D 모델과 대화 카메라에서 확인한다.

v2 입력 이미지는 기존 B 시트에서 여성 플레이어만 자른 참고 이미지를 입력으로 내장 image_gen을 사용했다. 시각 에셋 변경이므로 TDD 대신 원본과 생성 결과의 얼굴 간격·흰자 안의 눈동자 위치·눈동자 형태·전신 비율을 육안으로 비교한다. 실제 3D 모델의 비율·시선·동일 리그·표정 변형은 별도로 검증해야 한다.

이미지는 3D 게임 에셋으로 만들었을 때의 콘셉트다. [B안 제작 규격](../../village/production-v2/art-spec.md)에 따라 v7의 비율 대체물로 문·가구·카메라를 시험한 뒤 v7 얼굴을 사용하는 공통 베이스를 제작한다. 비율 시작값은 v4 B에서 계승한 값이다.
