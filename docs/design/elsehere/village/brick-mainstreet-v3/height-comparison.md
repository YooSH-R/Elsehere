# 브릭 메인스트리트 v3 — 층고 분위기 비교

> 이미지·ZIP·검수 기록은 Git에서 제외한 로컬 자료다. 아래 `artifacts/...` 경로는 로컬 보관본을 가리킨다.

**선택 결과: 브릭 메인스트리트 v3-B 채택.** v2의 재질과 건축 스타일을 유지하면서 B의 더 높은 1층 공간감을 최신 기준으로 사용한다. A/C는 비교 기록이다.

사용자 피드백: 제작 규격의 1층 높이와 캐릭터 키가 너무 비슷해 현실감이 떨어진다. 이에 인물 전체 키 1.4m를 목표로 유지하면서 1층 층고를 달리한 세 이미지를 생성했다. 이는 캐릭터 키 1.4m와 1.6m 자체를 비교한 이미지가 아니다.

| 후보 | 생성 지시의 1층 높이 | 생성 지시의 전체 건물 높이 | 분위기 판단 |
| --- | --- | --- | --- |
| A | 2.4m | 5.2m | 작고 아담한 상점가 |
| **B — 채택** | 3.0m | 5.8m | 건물과 캐릭터의 크기 차이가 뚜렷한 생활 공간 |
| C | 3.6m | 6.4m | 건물의 높이와 벽면 존재감이 더 강한 거리 |

전체 높이 목표는 1층 + 고정 2층 2.4m + 파라펫 0.4m다. 문 개구부 목표는 폭 2.0m × 높이 2.2m로 세 안에 동일하게 지시했다. 이는 이전 제작 규격의 1.8m 문을 확정 변경한 것이 아니라 이번 비교의 별도 가정이다.

## 해석 범위

**그림 속 수치는 생성 목표이며, 결과의 실제 축척을 측정·검증한 값이 아니다.** 생성 결과에서 문·어닝·층 구분띠의 위치가 일부 함께 달라졌으며, 완벽하게 층고만 바뀐 통제 실험이 아니다. C에서는 호텔 지붕 일부가 화면 위쪽에 걸려 보이는 차이도 있다. 인물·차량·거리의 배치와 크기는 대체로 유지되어 높고 낮은 거리의 분위기를 비교하는 용도로 사용한다.

선택한 B는 건물 속 공간이 느껴지면서도 C처럼 건축물이 강하게 압도하지 않는 방향이다. Unity에서는 캐릭터 1.4m·1층 층고 3.0m부터 검증한다. 정확한 3.0m가 이미 검증됐다는 뜻은 아니며, 실제 카메라·같은 모델·같은 축척에서 문과 창문까지 함께 조절한다.
