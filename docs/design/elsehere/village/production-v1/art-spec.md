# Elsehere 3D 제작 규격 v1

**보관용 이전안. 현재 제작에는 [B안 제작 규격 v2](../production-v2/art-spec.md)를 사용한다.** 아래 내용은 당시 초안이며, 최신 에셋 목록과 적용 순서도 production-v2에서 관리한다.

상태: **이 문서는 v2 기준으로 만든 이전 제작 초안이다. 최신 시각 기준은 브릭 메인스트리트 v3-B다.** 공통 재질·캐릭터 재사용 원칙은 유지하고 건물 높이·문 규격은 최신 선택에 맞춰 검토한다.
숫자는 콘셉트 이미지에서 측정한 실제 모델 값이 아니다. 한 캐릭터와 한 출입문을 먼저 만들어 검증한 뒤 공통 규격으로 고정한다.

**B 선택 반영:** [v3 층고 비교의 B](../brick-mainstreet-v3/height-comparison.md)를 채택했다. Unity 검증 시작값은 캐릭터 1.4m·1층 층고 3.0m다. 아래 2m 벽 높이·1.8m 문·4.4m 건물 높이 및 기존 치수도는 이전안이므로 그대로 적용하지 않는다. B 생성 시 사용한 2층 2.4m·파라펫 0.4m·총높이 5.8m와 문 2.0×2.2m는 추가 검토값이다. 2m 수평 격자에 문틀까지 포함한 개구부가 들어가는지 등 모듈 접합은 별도로 맞춘다.

- 전체 배치·재질 참고: [브릭 메인스트리트 v2](../../../../../artifacts/village/brick-mainstreet-v2/town-overview.png)

## 1. 무엇을 유지하는가

| 요소 | 제작 기준 |
| --- | --- |
| 미국 소도시 | 이어진 벽돌 상점, 평평한 파라펫, 큰 쇼윈도, 어닝, 세로 호텔 간판, 보도와 교차로 |
| 형태 | 짧고 넓은 건물, 두꺼운 창틀과 간판, 부드러운 모서리 |
| 재질 | 큰 색면과 무광 표면. 벽돌 줄눈·나뭇잎·옷감의 미세한 질감은 생략 |
| 캐릭터 | 큰 머리와 작은 몸, 공통 신체·본 구조. 인상은 얼굴·헤어·피부색·의상 조합으로 구분 |
| 나무 | 잎사귀 대신 3~5개의 큰 수관 덩어리. 가는 가지와 알파 잎 카드 없이 시작 |
| 생활감 | 카페·호텔·집의 입구와 NPC가 잘 보이게 배치. 장식은 통행 공간 밖에 둔다 |
| 비교 기준 | 같은 카메라·빛·노출에서 에셋을 비교. 눈 모양이나 특정 표정을 브랜드의 고정 표식으로 쓰지 않는다 |

마을 전체 콘셉트 이미지는 분위기 기준이다. 건물의 옆·뒤·실내, 실제 충돌 범위와 머티리얼 구성까지 정의한 제작 도면은 아니다.

## 2. 단위와 크기

게임 월드는 **1 Unity unit = 1m**로 맞춘다. 인물의 실제 인간 키를 재현하려는 값이 아니라 월드와 에셋의 상대 크기를 맞추는 기준이다. Unity 모델 Import의 Scale Factor와 단위 변환은 [공식 Model Import 문서](https://docs.unity3d.com/6000.3/Documentation/Manual/FBXImporter-Model.html)를 따른다.

### 캐릭터

캐릭터 비율은 [리틀 멍 v7 기준](../../mascot/little-mung-v7/README.md)에서 관리한다. 이전 비율 표는 삭제했다.

### 공간과 가구

치수는 너비 × 깊이 × 높이 순서다. 문은 프레임 바깥이 아니라 **실제로 통과할 수 있는 유효 폭·높이**를 쓴다.

| 항목 | 초안 | 이유 |
| --- | --- | --- |
| 출입문 유효 개구부 | 폭 1.80 × 높이 1.80m | 최대 헤어 폭 1.40m에 좌우 각 0.20m 여유, 키 대비 0.40m 상부 여유 |
| 문 모듈 | 폭 2.00 × 두께 0.20 × 높이 2.00m | 양옆 프레임 폭 0.10m. 문턱은 평평하게 처리 |
| 문 앞 비움 영역 | 2.40 × 2.40m | 도착·회전·NPC 대기와 화분을 겹치지 않게 하는 출발값 |
| 기본 벽 모듈 | 2.00 × 0.20 × 2.00m | 창·문·막힌 벽을 같은 격자에 교체 |
| 실내 상부 벽 보충 모듈 | 2.00 × 0.20 × 0.80m | 실내 높이를 늘리되 문·창 비율은 늘리지 않음 |
| 카페 / 상점 외관 | 6.00 × 6.00 × 4.40m | 2m 모듈 3칸, 2개 층과 상단 파라펫 |
| 호텔 외관 | 8.00 × 8.00 × 4.40m | 같은 모듈 4칸, 간판·입구 강조로 구별 |
| 집 외관 | 6.00 × 6.00 × 3.40m | 단층 몸체 + 단순 박공지붕 |
| 집 / 카페 / 호텔 로비 실내 | 6×6 / 8×8 / 8×8m | 내부 유효 바닥 크기 후보. 기존 분리 씬 구조 활용 |
| 실내 천장 높이 | 2.80m | 3인칭 카메라와 간판·얼굴 가림을 확인할 시작값 |
| 보도 | 총폭 4.00m | 가로수·가구 1.00m + 연속 통행 폭 3.00m |
| 차도 | 총폭 6.00m | 양방향 차로를 표현하는 시각적 기준. 교통 시뮬레이션 범위 아님 |
| 가게 사이 보행 연결 | 유효 폭 2.00m 이상 | 헤어와 벽의 간섭을 먼저 검사 |
| 의자 좌판 / 탁자 높이 | 최신 v7 규격 참조 | 앉기·손 도달은 애니메이션으로 검증 |
| 카운터 상판 높이 | 최신 v7 규격 참조 | 턱·팔·컵 접촉 확인 |
| 가로등 / 나무 높이 | 2.80 / 3.20m | 건물 간판보다 과도하게 커지지 않게 시작 |

외관과 실내는 기존처럼 별도 씬을 쓰므로 실내 바닥 크기가 외관과 완전히 일치할 필요는 없다. 다만 창문·문 디자인과 장소별 색은 이어져야 한다. 투명 유리로 실제 실내까지 보여주는 기능을 이미지 승인만으로 구현 완료로 보지 않는다.

## 3. 건물 모듈 접합 규칙

- 배치 격자: 기본 2.00m, 세부 위치 0.10m. 회전은 90도 단위.
- 바닥·도로는 윗면 Y=0, 원점은 타일 중심. 보도 윗면은 Y=0.10m이며 교차로에 낮아지는 연결면을 둔다.
- 벽 원점은 바닥 중앙, 정면은 +Z. 두께 0.20m는 Z 방향이며 중심 면 기준 ±0.10m.
- 벽 정면의 완성 외곽 폭이 정확히 2.00m가 되도록 만든다. 반복 모듈 접합면은 평평하게 두고 눈에 보이는 자유 모서리만 둥글린다.
- 코너에서 벽이 겹치거나 빛이 새면 전용 코너 변형을 추가한다. 직선 벽을 임의로 늘려 창문과 문 비율을 바꾸지 않는다.
- 간판·어닝·출입문은 교체 부품으로 둔다. 카페/상점/호텔은 공통 벽과 창에 간판·색·어닝을 조합한 Prefab Variant가 목표다.
- 건물 외곽 모서리 bevel은 0.03~0.06m, 작은 소품은 가장 짧은 변의 약 3~5%부터 검토한다. 모든 모서리를 과하게 부풀리지 않는다.
- 상점가 끝에는 같은 차도 6m + 양쪽 보도 4m의 연결 단면을 남긴다. 구역 확대 시 이 단면을 맞춘다. 별도 월드 스트리밍 시스템을 이 단계에 만들 필요는 없다.

## 4. 색과 재질

다음 HEX는 **이미지의 정확한 추출값이 아닌 제안 베이스 컬러**다. 빛을 받기 전의 sRGB 값이며, 최종 색은 Unity 기준 조명에서 조정한다.

| 토큰 | HEX | 용도 |
| --- | --- | --- |
| BrickCoral | #D97656 | 벽돌 건물의 큰 면 |
| WarmCream | #F2D6A7 | 창틀·띠장·간판 테두리 |
| AwningGreen | #326B57 | 카페·호텔 어닝 |
| SignNavy | #293E57 | 호텔 간판·금속 소품 |
| RoadSlate | #697791 | 차도 |
| PavementSand | #E8CFA8 | 보도 |
| LeafGreen | #82A947 | 큰 수관 |
| WoodBrown | #8A5D3C | 목재 가구 |
| WindowBlue | #6D9CB3 | 비투명한 스타일 창 표현 |
| LampWarm | #FFE1A1 | 조명 유리의 색 |

URP/Lit의 Metallic 0, Smoothness 0.15~0.30을 벽·헤어·의상·나무의 첫 비교값으로 사용한다. 바닥은 0.10~0.20, 도장된 간판은 0.25~0.35에서 확인한다. 이는 성능 수치가 아니라 룩 개발용 값이다. Metallic과 Smoothness의 의미는 [URP Lit 문서](https://docs.unity3d.com/6000.0/Documentation/Manual/urp/lit-shader.html)를 따른다.

- 기본 색 + 단순한 명암으로 시작하고, 벽돌·옷감·아스팔트의 사진 텍스처와 거친 노멀맵은 넣지 않는다.
- 벽돌은 일부 넓은 패치와 얕은 선으로 표현한다. 작은 벽돌을 수백 개 별도 Mesh로 만들지 않는다.
- 큰 수관 3~5개를 하나의 나무 Mesh로 합치는 것을 기본으로 검토한다.
- 간판 글자는 별도 텍스트/아틀라스로 교체할 수 있게 한다. Tripo가 생성한 깨진 글자를 건물에 구워 넣지 않는다.
- 기준 조명은 낮의 Directional Light 1개와 일정한 환경광. 실내외 노출은 함께 검토한다.
- 피사계심도는 끄고 시작한다. 콘셉트 그림의 전경 흐림을 게임 카메라에 그대로 적용하지 않는다.
- 램프마다 실시간 Point Light를 붙이지 않는다. 발광색과 필요한 소수 조명을 먼저 비교한다.
- 기본 창은 단순한 면으로 표현하되, 카페 내부 노출이 기능 요구로 확정된 구간은 별도 투명 재질·실내 배치로 검증한다.

공통 베이스·얼굴 A/B·표정·리그 기준은 [최신 제작 규격](../production-v2/art-spec.md)의 리틀 멍 v7 항목을 따른다.

## 6. 실제 프로젝트와 연결할 곳

현재 파일에서 확인한 값과 새 아트 초안을 구분한다. 스크립트 기본값은 기존 ScriptableObject의 실제 저장값과 다를 수 있다.

| 확인한 상태 | 아트 교체 때 할 일 |
| --- | --- |
| Unity 6000.3.26f1 / URP 17.3.0 | 현 버전에서 확인. 패키지 변경 없이 시작 |
| PlayerSandboxBuilder 기본 캡슐 높이 1.8m, 반지름 0.3m | 새 H=1.4m의 발 원점에 맞춰 충돌체와 Visual을 함께 검토 |
| PlayerCameraSettings 기본 pivot 1.5m, eye 1.6m, 거리 5m, pitch 20도 | 새 얼굴의 눈높이 측정. 카메라 시험값은 최신 v7 적용 순서 참조 |
| 문 Builder 기본 Trigger 1.4×2.4×0.7m, Visual 1.2×2.2m | 제안 문 유효 폭 1.8m에 맞춰 Trigger와 Visual을 별도로 검증. Visual만 넓혀 끝내지 않음 |
| 기존 문 ArrivalPoint는 +Z 방향 2m | Trigger 밖에 서고 바로 재진입하지 않는지 확인. 문은 +Z가 바깥을 향함 |
| HomeScene ↔ TownScene ↔ CafeScene/HotelScene | 현 공간 연결과 Doorway Id를 유지하며 디자인 교체 |
| 공간 프리팹의 디자인은 Builder에서 덮어쓰지 않는 규약 | 원본 기능 루트를 보존하고 아트 자식·공간 프리팹을 교체 |

거대한 머리에 맞춰 충돌체를 과도하게 키우면 발 주변 통행감이 어색해지고, 작은 기존 캡슐을 그대로 쓰면 머리가 벽을 뚫을 수 있다. 정확한 충돌 반지름은 이 문서에서 확정하지 않는다. **머리 최대 폭 1.4m의 시각 외곽까지 검사**하며, 문·벽·NPC가 만나는 코너에서 이동을 확인한 뒤 결정한다.

적용 경로는 기존 규약을 따른다.

- 공통 건축·인물 소스: `Assets/Art/Common/`
- 장소별 아트: `Assets/Art/Town/`, `Home/`, `Cafe/`, `Hotel/`
- 기능 프리팹: `Assets/Prefabs/<기능>/`
- 조절 수치: 기능별 `Assets/Data/<기능>/`의 기존 설정 또는 필요한 새 설정
- 외부 에셋 원본: `Assets/ThirdParty/<에셋 이름>/`; 출처·사용 조건은 `CREDITS.md`
- 검증 후보: `Assets/Scenes/Sandbox/TownArtSandbox.unity`
- 씬·프리팹·머티리얼·meta는 Editor 또는 Builder로 생성한다. 이번 문서 작성에서는 생성하거나 변경하지 않았다.

## 7. 제작 비용을 제어할 초깃값

아래는 **프로젝트가 정한 제작 목표 초안**이며 Unity의 보장 성능이나 실제 측정값이 아니다.

| 단위 | 첫 예산 |
| --- | --- |
| 캐릭터 1명(헤어·옷 포함) | 8k~15k triangles, 전체 2~3개 재질 슬롯부터 검토 |
| 조립 건물 외관 1동 | 5k~12k triangles, 공유 재질 2~4종 |
| 나무 1종 | 0.5k~1.5k triangles |
| 보통 소품 1종 | 0.1k~1k triangles |
| 캐릭터 텍스처 | 우선 1024px 이하, 대화 클로즈업 검사 후 필요한 부분만 상향 |
| 환경 공유 아틀라스 | 우선 1024px 이하. 각 벽에 2K 텍스처를 별도로 부여하지 않음 |
| 같은 화면 인물 비교 | 1명 → 4명 → 8명, 실제 브라우저에서 프레임 시간·메모리 측정 |
| PC Web 검토 목표 | 1080p, 평균 30fps 이상 출발 목표. 테스트 장비·브라우저·90/95백분위 프레임 시간을 함께 기록 |

삼각형 수가 낮아도 많은 개별 Renderer, 재질, 투명 오브젝트, 실시간 조명으로 비용이 커질 수 있다. 모듈은 편집용 단위와 렌더링 단위를 구분해 평가한다. 기계적으로 모두 합치거나 LOD를 먼저 양산하지 않는다.

## 8. 제작 순서와 통과 기준

| 순서 | 산출물 | 통과 기준 |
