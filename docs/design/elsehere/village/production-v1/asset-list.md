# Elsehere MVP 제작 에셋 목록 v1

**보관용 이전안. 현재 제작에는 [B안 에셋 목록 v2](../production-v2/asset-list.md)를 사용한다.** 아래 치수와 제작 순서는 이전 초안이다.

[제작 규격](art-spec.md)과 함께 사용한다. 전체 목록은 **제작 범위 제안**이며, 모델 파일이나 Unity 프리팹이 이미 존재한다는 뜻이 아니다. 행 하나는 제작 묶음이고 실제 Mesh·파일·배치 수와 다르다.

**현재 기준은 브릭 메인스트리트 v3-B다.** 아래 에셋 종류와 재사용 구성은 유지하되, 2m 벽 높이·1.8m 출입문 등 v1의 치수는 이전안이다. [선택된 B와 검증 시작값](../brick-mainstreet-v3/height-comparison.md)을 먼저 확인하고 건축 모듈의 높이·문틀 접합을 맞춘다.

우선순위: **S0 크기/재사용 검증 → S1 MVP 구성 → S2 장식 보강**. S2는 시각 장식의 우선순위이며 학습 기능을 제외하는 구분이 아니다.

## 1. 캐릭터

캐릭터 제작 묶음은 [최신 에셋 목록](../production-v2/asset-list.md)의 리틀 멍 v7 기준으로 관리한다. 이전 캐릭터 목록은 삭제했다.

## 6. 어떤 방식으로 확보할 것인가

| 대상 | 우선 방식 | 선택 이유와 확인 사항 |
| --- | --- | --- |
| 벽·문·창·도로 | 단순 Mesh 직접 제작 또는 검증된 모듈 키트 수정 | 정해진 2m 접합과 1.8m 개구부를 정확히 맞추기 쉬움 |
| 공통 캐릭터 | 기준 4뷰 → 베이스 후보 1종 → 토폴로지/리그 정리 | Tripo는 후보 생성 단계에 활용 가능. 교체 가능한 베이스 여부는 별도 검사 |
| 헤어·의상 | 확정 베이스 위에서 제작 | 독립 생성 모델의 비율·목 접합·스킨 차이 방지 |
| 가구·거리 소품 | 무료 에셋 후보를 먼저 비교, 맞지 않는 핵심 소품만 제작 | 색 변경만으로 맞는지, 실루엣·재질·수정 가능 파일·사용 조건 확인 |
| 커피 머신 등 대표 소품 | 필요할 때 개별 모델 생성 후보 | 마을 전체나 가게 한 동을 통째로 생성해 모듈로 가정하지 않음 |

무료 에셋의 구체 제품은 아직 선정하거나 다운로드하지 않았다. 후보 비교 항목은 파일 형식·원점·실제 크기·삼각형 수·재질/텍스처 수·URP 표현·개작 가능 여부·라이선스·출처다. 원본은 ThirdParty에 보관하고 수정본은 기능별 Art에 둔다.

## 7. 다음 제작에 넘길 입력 묶음

1. **캐릭터 베이스 1종**: 같은 정자세·정사영·스케일의 정면/좌측/우측/후면. 바닥선과 정수리선 일치. 소품·그림자·바닥판 없이 팔과 몸의 경계가 보이게 한다. 서로 다른 사람처럼 재생성된 4장을 한 모델의 4뷰로 쓰지 않는다.
2. **카페 전면 1구간**: 2m 벽, 1.8m 유효 출입문, 어닝·간판의 분리 범위를 표시한 정면/측면 치수도.
3. **공통 색·재질**: art-spec의 팔레트와 v2 원본 이미지. 조명 효과까지 베이스 텍스처에 굽지 않는다.
4. **출력 검사**: 불러온 후 1.4m 인물과 1.8m 개구부를 실제 Bounds/눈높이/이동으로 확인. 같은 리그에 헤어·의상 2종을 교체.
5. **확장 조건**: 위 시험이 통과하면 건물·NPC 조합을 늘린다. 먼저 여러 전신 모델을 대량 생성하는 방식은 피한다.

이 목록은 에셋 기획과 제작 입력 정의다. 자동 생성 도구, 외부 에셋 선정, 모델 생성, 리깅, Unity 가져오기를 실행한 기록이 아니다.
