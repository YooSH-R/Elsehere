# Elsehere B안 제작 에셋 목록 v2

[B안 제작 규격](art-spec.md)의 1층 4m·2층 3m·상점 총높이 7.4m와 출입문 유효 2.0×2.2m를 적용한다. ID는 이전 목록을 이어 사용하며, 각 행은 제작 묶음이다. 이미 생성된 3D 모델의 재고 목록은 아니다.

우선순위는 **S0 크기·교체 검증 → S1 MVP 공간 완성 → S2 장식 보강**이다. NPC 시트의 인원수와 실제 씬에 배치할 인원수는 별개다. 작업 선후 관계와 통과 기준은 [Unity 적용 순서](unity-application-plan.md)에 둔다.

실제 최초 배치는 플레이어 외형 2종, 길 안내 행인 1명, 바리스타 1명, 호텔리어 1명부터 제안한다. 노년 헤어·안경·추가 의상은 공통 베이스 검증 뒤 추가한다. 피부색이나 성별을 직업에 고정하지 않는다. 사용자가 조절하는 전체 커스터마이징 UI는 별도 기능 범위다.

## 6. 확보 방법과 납품 조건

Sandbox 외관은 TallWindowV2, WarmShopWindowV2, 물결 차양 모듈, 호텔 곡선 차양, GardenBedV2, StreetLampV2, 상자·입간판을 공유한다. 북쪽에는 폭 6m·깊이 5.2m·높이 5.8~7.3m의 DistantShopV2 3종을 조합하며 실내와 기능은 없다. 실제 기능 건물을 늘릴 때 해당 배경 외관을 교체한다. 세부 모듈과 재질은 [외관 아트 문서](../../../../unity/mainstreet-art.md)를 따른다.

벽·도로·문틀은 치수 조정이 쉬운 단순 메시 또는 검증한 모듈 키트를 우선한다. 가구·소품은 무료 후보의 수정 가능 파일·사용 조건·재질·크기·폴리곤 수를 비교한 뒤 채택한다. 외관 아트는 Unity 공통 모듈로 제작하고, 차량은 공식 CC0 Kenney Car Kit 3.1의 truck-flat.fbx와 공통 팔레트만 도입한다. 원본 라이선스는 Assets/ThirdParty/KenneyCarKit/License.txt에 함께 둔다. Tripo 유료 생성은 사용하지 않는다.

Tripo는 **선택된 비율의 캐릭터 베이스 한 체 또는 개별 소품 후보**를 만드는 데 활용할 수 있다. 비교 시트 전체나 여러 캐릭터를 한 모델의 입력으로 쓰지 않는다. 한 인물의 일관된 정면·측면·후면과 분리할 헤어·옷 범위를 먼저 정한다. 생성 결과는 DCC에서 정리한 뒤 공통 리그·스킨·표정 검사를 통과해야 한다.

각 에셋에는 수정 가능한 원본, 내보낸 모델, 연결된 텍스처, 단위·축·원점, 삼각형·재질 수, 출처·라이선스 정보를 함께 전달한다. 기능용 피벗·Collider·Trigger는 Unity에서 검사한다. 외부 원본은 `Assets/ThirdParty/`, 가공본은 `Assets/Art/<기능>/`에 두고 출처를 `CREDITS.md`로 관리한다.
