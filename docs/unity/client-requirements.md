# 이용 환경과 최소 사양

Elsehere는 설치 없이 브라우저에서 실행하는 Unity Web(WebGL) 게임입니다. 이 문서는 이용자의 PC·모바일 기기에 필요한 조건을 정리합니다. 빌드 설정과 코드로 정해지는 조건은 **확정**, 실제 기기 성능 측정이 필요한 조건은 **미정(권장 기준)**으로 구분합니다.

정식 지원 대상은 PC 웹입니다. 모바일 웹은 화면·터치 조작·그래픽 품질을 대응해 두었지만, 대상 브라우저와 기기 성능은 검증 전이므로 지원 범위를 확정하지 않았습니다.

## 공통 조건 (확정)

| 항목 | 조건 | 기준 |
| --- | --- | --- |
| 그래픽 | WebGL 2를 지원하는 브라우저. WebGL 1로는 실행되지 않습니다. | `ProjectSettings.asset`의 Web 그래픽 API |
| 브라우저 | [Unity 6 Web이 지원하는 브라우저](https://docs.unity3d.com/6000.3/Documentation/Manual/webgl-browsercompatibility.html)의 최신 버전 (Chrome, Edge, Firefox, Safari) | Unity 6000.3 Web 빌드 |
| 접속 | HTTPS 주소로 접속 | 브라우저는 보안 연결에서만 마이크를 엽니다. |
| 마이크 | 권장. 마이크 장치가 있고 브라우저의 마이크 권한을 허용해야 [말하기]를 쓸 수 있습니다. 마이크를 쓸 수 없으면 [텍스트로 입력]으로 대화합니다. | `VoiceMicrophone.jslib`, 기능명세서 F-24 |
| 소리 | 스피커나 이어폰. NPC 대사를 음성으로 들려줍니다. 스피커 소리가 마이크로 다시 들어가지 않도록 이어폰을 권장합니다. | - |
| 첫 접속 내려받기 | 게임 파일 약 130MB(압축 전송 기준). 빌드마다 달라집니다. | 배포한 `Build/` 파일의 `Content-Length` |
| 다시 접속 | 받은 게임 파일을 브라우저 저장 공간에 보관해 다시 쓰므로 그만큼의 여유 공간이 필요합니다. 시크릿 창이나 저장 공간을 막은 브라우저는 매번 다시 받습니다. | `webGLDataCaching` |
| 메모리 | 게임 탭 하나가 최대 2GB까지 사용할 수 있습니다. | `webGLMaximumMemorySize` |
| 네트워크 | 대화 중에는 녹음을 서버로 보내고 NPC 음성을 받으므로 연결이 끊기지 않아야 합니다. | - |

브라우저가 소리 자동재생을 막으면 첫 클릭·키 입력·터치 뒤에 소리가 납니다.

## PC

| 항목 | 조건 | 구분 |
| --- | --- | --- |
| 입력 | 키보드와 마우스 | 확정 |
| 화면 | 브라우저 창 전체를 사용합니다. UI는 1920×1080 기준으로 창 크기에 맞춰 늘고 줄어듭니다. | 확정 |
| 그래픽 품질 | 렌더링 배율 0.8, 그림자 맵 2048, 그림자 거리 30m, 부드러운 그림자 | 확정 |
| 운영체제 | Windows 10 이상, macOS 11 이상 | 미정(권장 기준) |
| CPU | 듀얼코어 2GHz급 이상 | 미정(권장 기준) |
| RAM | 8GB 이상 | 미정(권장 기준) |
| 그래픽 장치 | WebGL 2가 동작하는 내장 그래픽 이상 | 미정(권장 기준) |

## 모바일 (지원 범위 미정)

| 항목 | 조건 | 구분 |
| --- | --- | --- |
| 입력 | 터치. 왼쪽 아래 조이스틱으로 이동하고 오른쪽 빈 영역을 끌어 시점을 돌립니다. | 확정 |
| 화면 | 가로·세로 모두 표시하고 노치·홈 표시줄 영역은 비웁니다. | 확정 |
| 그래픽 품질 | 렌더링 배율 0.8, 그림자 맵 1024, 그림자 거리 50m, 부드러운 그림자 끔 | 확정 |
| 브라우저 | Android Chrome, iOS·iPadOS Safari | 미정(검증 전) |
| RAM | Android 6GB 이상, iPhone 4GB 이상 | 미정(권장 기준) |
| 네트워크 | 첫 접속은 Wi-Fi 권장 | 권장 |

휴대폰·태블릿은 브라우저가 모바일 기기로 알리거나 주 입력 장치가 손가락일 때로 판별합니다. 터치스크린이 달린 노트북은 PC로 봅니다. 판별과 품질 값의 상세는 [브라우저 그래픽 품질](setup.md#브라우저-그래픽-품질)에 있습니다.

## 확정하지 않은 사항

- **PC·모바일의 CPU·RAM·기기 세대:** 위 권장 기준은 탭 메모리 상한과 그래픽 설정에서 잡은 값입니다. 저사양 노트북과 휴대폰에서 로딩 시간, 프레임, 탭 메모리를 측정한 뒤 확정합니다.
- **모바일 메모리:** 받은 게임 파일을 풀어 메모리에 올리므로 RAM이 적은 기기와 iOS Safari에서 탭이 닫힐 수 있습니다. 실제 기기에서 확인하지 않았습니다.
- **모바일 프레임 상한:** 프레임은 브라우저 화면 갱신 주기를 따릅니다. 발열·배터리를 위한 상한은 [성능 검증 후 결정](setup.md#모바일-화면과-web-템플릿)합니다.
- **모바일 지원 브라우저:** 터치 조작, 마이크 권한, 자동재생 정책을 대상 브라우저별로 검증한 뒤 정합니다.

빌드 설정(그래픽 API, 메모리 상한, 품질 값)이나 게임 파일 크기가 크게 바뀌면 이 문서를 함께 고칩니다.
