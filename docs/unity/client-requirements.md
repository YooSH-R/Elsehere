# 이용 환경과 최소·권장 사양

Elsehere는 설치 없이 브라우저에서 실행하는 Unity Web(WebGL) 게임입니다. 이 문서는 이용자의 PC·모바일 기기에 필요한 조건을 정리합니다. 빌드 설정과 코드로 정해지는 조건은 **확정**, 실제 기기 성능 측정이 필요한 조건은 **추정**(측정 전 값)으로 구분합니다.

정식 지원 대상은 PC 웹입니다. 모바일 웹은 화면·터치 조작·그래픽 품질을 대응해 두었지만, 대상 브라우저와 기기 성능은 검증 전이므로 지원 범위를 확정하지 않았습니다.

## 공통 조건 (확정)

| 항목 | 조건 | 기준 |
| --- | --- | --- |
| 그래픽 | WebGL 2를 지원하는 브라우저. WebGL 1로는 실행되지 않습니다. | `ProjectSettings.asset`의 Web 그래픽 API |
| 브라우저 | [Unity 6 Web이 지원하는 브라우저](https://docs.unity3d.com/6000.3/Documentation/Manual/webgl-browsercompatibility.html)의 최신 버전 (Chrome, Edge, Firefox, Safari) | Unity 6000.3 Web 빌드 |
| 접속 | HTTPS 주소로 접속 | 브라우저는 보안 연결에서만 마이크를 엽니다. |
| 마이크 | 권장. 마이크 장치가 있고 브라우저의 마이크 권한을 허용해야 [말하기]를 쓸 수 있습니다. 마이크를 쓸 수 없으면 [텍스트로 입력]으로 대화합니다. | `VoiceMicrophone.jslib`, 기능명세서 F-24 |
| 소리 | 스피커나 이어폰. NPC 대사를 음성으로 들려줍니다. 스피커 소리가 마이크로 다시 들어가지 않도록 이어폰을 권장합니다. | - |
| 첫 접속 내려받기 | 게임 파일 PC 약 125~130MB, 휴대폰 약 135~140MB(압축 전송 기준). 휴대폰은 휴대폰 GPU가 읽는 ASTC 텍스처 데이터를 따로 받아 PC보다 약 10MB 큽니다. 빌드마다 달라집니다. | 배포한 `Build/` 파일의 `Content-Length`, [PC용·휴대폰용 텍스처 데이터](setup.md#pc용휴대폰용-텍스처-데이터) |
| 다시 접속 | 받은 게임 파일을 브라우저 저장 공간에 보관해 다시 쓰므로 그만큼의 여유 공간이 필요합니다. 시크릿 창이나 저장 공간을 막은 브라우저는 매번 다시 받습니다. | `webGLDataCaching` |
| 메모리 | 게임 탭 하나가 최대 2GB까지 사용할 수 있습니다. | `webGLMaximumMemorySize` |
| 네트워크 | 대화 중에는 녹음을 서버로 보내고 NPC 음성을 받으므로 연결이 끊기지 않아야 합니다. | - |

브라우저가 소리 자동재생을 막으면 첫 클릭·키 입력·터치 뒤에 소리가 납니다.

## 모바일 (지원 범위 미정)

| 항목 | 조건 | 구분 |
| --- | --- | --- |
| 입력 | 터치. 왼쪽 아래 조이스틱으로 이동하고 오른쪽 빈 영역을 끌어 시점을 돌립니다. | 확정 |

| 그래픽 품질 | 렌더링 배율 0.8, 그림자 맵 1024, 그림자 거리 50m, 부드러운 그림자 끔 | 확정 |

휴대폰·태블릿은 브라우저가 모바일 기기로 알리거나 주 입력 장치가 손가락일 때로 판별합니다. 터치스크린이 달린 노트북은 PC로 봅니다. 판별과 품질 값의 상세는 [브라우저 그래픽 품질](setup.md#브라우저-그래픽-품질)에 있습니다.

## 최소·권장 사양 (추정)

실제 기기에서 측정하기 전의 추정값입니다. 최소 사양은 게임이 끝까지 열리고 이용 중 탭이 닫히지 않는 수준, 권장 사양은 마을에서 끊김 없이 움직이고 대화할 수 있는 수준을 뜻합니다.

| 항목 | 최소 사양 | 권장 사양 |
| --- | --- | --- |
| 운영체제 | Windows 10 이상, macOS 11 이상 | Windows 10 이상, macOS 11 이상 |
| PC CPU | 4코어, Intel 8세대 Core i5·AMD Ryzen 3000 시리즈급 | Intel 11세대 Core i5·AMD Ryzen 5 5000 시리즈급 이상 |
| PC 그래픽 | WebGL 2가 동작하는 내장 그래픽(Intel UHD 620급) | Intel Iris Xe·AMD Radeon 내장 그래픽 이상, 또는 GeForce GTX 1650급 외장 그래픽 |
| PC RAM | 8GB | 16GB |
| Mac | Intel Mac은 위 PC 기준, Apple M1 | Apple M1 이상 |
| Android (지원 범위 미정) | RAM 6GB 중급 기기 | RAM 8GB 이상 상위 기기 |
| iPhone (지원 범위 미정) | RAM 6GB(iPhone 12 Pro·13 Pro·14 이상) | RAM 8GB(iPhone 15 Pro 이상) |
| 네트워크 | 10Mbps(첫 접속 내려받기 약 100초) | 50Mbps 이상(약 20초) |

추정 근거는 다음과 같습니다.

- Web 빌드는 스레드를 쓰지 않아(`webGLThreadsSupport: 0`) 게임 코드가 한 스레드에서 돕니다. 그래서 코어 수보다 코어 하나의 성능이 프레임에 크게 영향을 줍니다. 마을에는 NPC가 많아 CPU 부담이 큽니다.
- 게임 탭 하나가 최대 2GB까지 쓰고, 여기에 브라우저와 다른 프로그램이 더해지므로 PC RAM은 8GB가 바닥입니다.
- iOS Safari에서 탭 메모리를 넘겨 페이지가 다시 열린 사례가 있어 RAM 4GB iPhone(iPhone 11~13 일반 모델 등)은 최소 사양에서 뺐습니다. 휴대폰은 PC보다 큰 데이터를 받아 풀어 올립니다.
- 그래픽 품질 값은 내장 그래픽에서도 돌아갈 수준으로 잡았지만, NPC가 몰린 곳에서는 프레임이 떨어질 수 있습니다.
- 네트워크 값은 PC 첫 접속 내려받기 크기(약 128MB)로 계산했습니다. 다시 접속하면 저장해 둔 파일을 씁니다.

## 확정하지 않은 사항

- **최소·권장 사양:** 위 추정값은 빌드 크기, 탭 메모리 상한, 그래픽 설정에서 잡은 값입니다. 기기 등급별로 같은 순서(캐시 없는 첫 접속과 다시 접속의 로딩 시간, 마을의 정해진 길을 걸을 때 프레임 평균과 하위 1%, 실내 드나들기, 음성 대화, 20~30분 이용 중 탭 메모리와 탭 닫힘)를 측정한 뒤 확정합니다.
- **모바일 메모리:** 받은 게임 파일을 풀어 메모리에 올리므로 RAM이 적은 기기에서 탭이 닫힐 수 있습니다. iOS Safari에서 탭 메모리를 넘겨 페이지가 다시 열린 사례가 있었고, 기기별 한계는 측정 전입니다.
- **모바일 프레임 상한:** 프레임은 브라우저 화면 갱신 주기를 따릅니다. 발열·배터리를 위한 상한은 [성능 검증 후 결정](setup.md#모바일-화면과-web-템플릿)합니다.
- **모바일 지원 브라우저:** 터치 조작, 마이크 권한, 자동재생 정책을 대상 브라우저별로 검증한 뒤 정합니다.

빌드 설정(그래픽 API, 메모리 상한, 품질 값)이나 게임 파일 크기가 크게 바뀌면 이 문서를 함께 고칩니다.
