# 매장 전용 모델

세탁기·건조기·이발 의자·일반 오락기는 기존에 제작한 Tripo 모델을 사용한다. 원본 GLB는 로컬 `artifacts/tripo-models/laundry-barber-arcade-v1`에 보관한다. Unity에는 최적화된 세탁기와 나머지 모델을 Blender로 변환한 FBX·기본색 텍스처만 넣는다. 고해상도 세탁기 원본은 배포에 포함하지 않는다.

- 모델·재질: `Assets/Art/World/ShopModels/`
- 재사용 외형 프리팹: `Assets/Prefabs/World/ShopModels/`
- 적용: `Tools/A305/World/Apply Shop Models`
- 실제 Play 검수: `Tools/A305/World/Verify Shop Models`

외형은 기존 설비의 `TripoVisual` 자식으로 연결한다. 기존 설비의 위치·호버 단어·충돌·앉기 기준점은 유지하고, 도형 렌더러만 숨긴다. 외형을 바꾸려면 공용 모델 프리팹의 시각 모델을 교체한다. 적용 도구는 이미 설치한 외형을 덮어쓰지 않는다. 새 모델의 크기가 달라지면 기존 충돌과 좌석 기준점에 맞는지 다시 확인한다.

이발 의자는 1.6m 리틀 멍의 실제 착석 기준에 맞춘다. 발받침을 포함한 전체 경계에 맞춰 축소하지 않고, 좌판 윗면을 바닥에서 0.64m에 맞춰 균등 확대한다. 원본 모델에서 좌판 높이는 전체 높이의 약 0.48이므로 전체 높이 약 1.33m, 전체 폭 약 0.94m, 깊이 약 1.16m가 된다. 좌판 중앙을 기존 앉기 기준점에 정렬하고 등받이·팔걸이에는 별도 단순 충돌체를 둔다. `Tools/A305/World/Fit Barber Chairs To Little Mung`으로 기존 배치를 보정하고, `Verify Barber Chair Sitting`으로 실제 앉기·일어서기와 PC·모바일 화면을 확인한다.

공용 프리팹은 URP Lit 재질을 공유하며, 텍스처는 WebGL에서 최대 1024로 가져온다. 모델에는 애니메이션·추가 리그·읽기 가능한 CPU 메시 사본을 사용하지 않는다. 장소 전환 시 자산 해제는 [마을 스트리밍](town-streaming.md)의 공통 전환 흐름을 따른다.

이 모델은 기존 생성 결과를 로컬에서 변환한 것이다. 적용 도구는 Tripo 생성·변환 API를 호출하지 않는다. 모델의 출처 식별자는 각각 세탁기 `83eed23f-8907-44fd-81dd-1f04cf7b4581`, 건조기 `cf4d2d49-a1e4-4344-a028-a5caff10944e`, 이발 의자 `531d6fc2-9551-446a-840c-c65744517585`, 오락기 `33c028cb-c575-4321-976d-8c091c76557b`이다.
