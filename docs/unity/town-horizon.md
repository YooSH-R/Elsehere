# 마을 원경과 길 끝 경계

TownScene 북쪽에는 먼 상점가, 남쪽에는 주택가 이미지를 배치한다. 하늘·구름·별은 텍스처를 추가하지 않는 전용 하늘 셰이더로 표시한다. 하늘 재질은 기존 WeatherPresenter의 하늘색·별 설정을 받아 낮·밤과 날씨 변화에 연결된다. 먼 마을도 환경광과 해의 밝기를 받아 밤에는 어두워진다.

## 배치와 편집

- 길 끝의 화단·울타리는 `Environment/TownHorizonBoundaries`에 있다. 공통 `BoundaryOverlook` 프리팹을 북쪽 z=69, 남쪽 z=-32에 배치한다. 화단 사이를 연결하는 난간과 폭 40m의 연속 충돌체가 이동과 점프를 막는다.
- 원경은 `Lighting/TownHorizonScenery` 아래의 북남 프리팹에 있다. 접근 불가능한 풍경은 학습 사물의 충돌·호버 영역을 추가하지 않는다. 가까운 화단과 난간은 공용 단어 연결을 사용한다.
- `Assets/Art/World/TownHorizon/TownHorizonAtlas.png`의 위쪽 절반은 상점가, 아래쪽 절반은 주택가다. 투명 하늘 부분에는 Skybox가 보인다. 이미지 원본은 내장 이미지 생성 도구로 만든 게임 배경이다.
- 원경은 북쪽 반지름 160m, 남쪽 145m의 곡면 카드에 배치한다. 이미지 기반 원경이므로 가까이 걸어 들어가는 공간을 추가할 때는 해당 방향의 배경 카드와 경계를 함께 이동하거나 교체한다.
- 하늘·원경 재질과 프리팹은 없을 때 생성하며 이후 Prefab Mode 편집을 유지한다.

**Tools → A305 → World → Apply Town Horizon**으로 저장된 에셋과 배치를 적용한다. 기존 `ExtensionEnd` 중 북남 두 끝만 비활성화하고 새 경계를 배치한다. 동서 구름은 별도 프리팹으로 관리한다.

## 메모리 제한

원경 한 장을 북남 카드가 공유한다. 가져오기 크기는 1024×512이고 읽기/쓰기는 꺼서 CPU용 픽셀 복사본을 유지하지 않는다. Mipmap을 사용하며 Standalone은 DXT5, WebGL은 ETC2 RGBA8로 압축한다. 알파를 포함한 이 크기의 압축 텍스처는 Mipmap 포함 GPU 데이터가 약 0.67MiB다. Editor의 런타임 메모리 측정에는 별도 Unity 객체·드라이버 비용이 포함될 수 있다.

하늘은 텍스처를 추가하지 않는다. 원경 카드는 각각 64개 삼각형이며, 화단의 같은 형태와 재질별 메시를 공유하고 난간을 하나의 메시로 합친다. 새 원경 텍스처의 Editor 로드 메모리는 2MiB 이하인지 Builder에서 검사한다.

## 검수

**Tools → A305 → World → Verify Town Horizon**은 Play로 실제 플레이어의 북남 이동을 막는지 확인하고 낮·밤 카메라 화면을 저장한다. 검수 화면과 메모리 보고서는 로컬 `artifacts/unity/town-horizon/`에 저장하며 Git에는 포함하지 않는다. 메모리 보고서는 전용 에셋 기준 측정이며 전체 WebGL 프로세스 메모리 증감과는 구분한다.
