# ELSEHERE 시연 시나리오 — 비 오는 저녁, 햄버거 한 끼

발표 전 시연에 사용할 배포 주소에서 화면 문구와 버튼 위치를 확인합니다.

비 오는 마을에서 호텔 직원에게 택시를 부탁하고, Maple Burger에서 저녁을 주문한 뒤 대화 노트에서 같은 상황을 다시 연습합니다. 약 **5~7분**이 걸립니다.

| 장면 | 확인할 기능 |
| --- | --- |
| 호텔 로비의 Owen | 지난 대화 기억과 무례한 말에 따른 호감도 변화 |
| 호텔 프런트의 Jake | 음성으로 택시 부탁하기, 추천 문장, 대화 목표 체크 |
| 택시의 Joe | 말한 목적지 인식과 실제 이동·하차 |
| Maple Burger의 John과 Rosa | 먼저 다가오는 NPC, 단골 응대, 주문 조건 판정과 코인 결제 |
| 휴대폰의 대화 노트 | 대화 피드백과 같은 상황 다시 연습 |

## 1. 접속과 조작

[개발 시연 사이트](https://dev.elsehere.kr/)를 PC의 Chrome 또는 Edge에서 엽니다. WebGL 2를 지원하는 브라우저와 스피커 또는 이어폰을 준비합니다. 음성으로 진행하려면 브라우저의 마이크 권한 요청에서 **[허용]**을 누릅니다. 마이크 사용이 어려우면 화면 아래 입력칸에 같은 문장을 입력해 진행할 수 있습니다.

| 조작 | 동작 |
| --- | --- |
| `W` `A` `S` `D` 또는 방향키, `Shift` | 이동, 달리기 |
| 마우스 왼쪽 버튼을 누른 채 끌기, 마우스 휠 | 시점 돌리기, 확대·축소 |
| NPC 클릭, `E` | 가까이 가서 NPC 클릭으로 말을 걸고, `E`로 대화 제안을 수락합니다. `E`로 택시에도 탈 수 있습니다. |
| `Esc`, 건물 문 | 창을 닫습니다. 열린 창이 없는 상태에서 대화 중이면 대화를 종료합니다. 건물은 문으로 걸어서 출입합니다. |

화면 아래 대화창에서 **[말하기] → 영어로 발화 → [종료]** 순서로 녹음합니다. 입력칸에 변환된 문장을 확인하고 오른쪽의 **[보내기]** 또는 `Enter`를 누릅니다. 인식이 다르면 보내기 전에 글자를 고칩니다. **[힌트]**로 추천 문장을 펼쳐 누르면 입력칸에 들어갑니다. NPC 대사는 **[다시 듣기]**, **[뜻]**, **[자막 켜기]**로 확인할 수 있습니다.

## 2. 게스트로 시연 퀘스트 시작

| 화면 | 클릭·조작 | 확인할 결과 |
| --- | --- | --- |
| Elsehere 첫 화면 | 가운데 **[게스트로 둘러보기]** 클릭 | 캐릭터 선택 화면이 열립니다. |
| 캐릭터 선택 | 캐릭터를 고르고 음성으로 시연할 경우 **음성 처리 동의**를 켠 뒤 **[시작하기]** 클릭 | 레벨 테스트 안내가 나옵니다. |
| 레벨 테스트 | **[건너뛰기]** 클릭 | 게스트 초급으로 입장합니다. |
| 내 방 튜토리얼 | **[건너뛰기]** 클릭 후 확인 창에서 다시 **[건너뛰기]** | 퀘스트를 열 수 있습니다. 시연 전용 환경에서 호텔로 바로 입장했다면 로비에서 다음 단계로 진행합니다. |
| 게임 화면 | 화면 **왼쪽 위 책 모양 [퀘스트]** 버튼 → **[이야기]** → **‘비 오는 저녁, 햄버거 한 끼’** 카드 | 퀘스트 도장 지도가 열립니다. |
| 도장 지도 | **[퀘스트 시작]** 클릭 | 왼쪽 위에 **‘1 / 3 호텔에서 저녁 나들이 준비’**와 **‘택시 부탁하기’** 목표가 표시됩니다. 첫 시작은 1일차 오후 5시 28분 무렵의 비 오는 날씨입니다. |

내 방에서 시작했다면 문으로 걸어 나갑니다. 마을 **왼쪽 아래 미니맵의 금색 호텔 표시**를 따라 큰길 동쪽 보도로 이동한 뒤 호텔 문을 통과합니다. 미니맵을 클릭하면 큰 지도가 열립니다.

## 3. 호텔에서 Owen과 Jake 만나기

| 화면 | 클릭·조작 | 확인할 결과 |
| --- | --- | --- |
| 호텔 로비 | 프런트 데스크 옆 **Owen**을 이름표로 확인해 클릭. **[대화하기]** 클릭 또는 `E` | Owen이 지난 일을 기억해 경계하는 말투로 맞이합니다. 이름 옆 초기 호감도는 **−40**입니다. |
| Owen 대화창 | `Shut up.`을 한 번 보내기 | 무례 경고가 1회 표시되고 호감도가 내려갑니다. |
| Owen 대화창 | **[대화 종료]** 클릭. 피드백 준비 안내가 뜨면 **[나중에 확인하기]** 클릭 | 로비로 돌아옵니다. |
| 호텔 로비 | 프런트 데스크 뒤 **Jake**를 클릭하고 **[대화하기]**를 누름 | Jake와 대화가 시작됩니다. |
| Jake 대화창 | 필요하면 **[힌트]**를 한 번 열어 추천 문장을 보여 줌. `Could you call me a taxi, please?` 보내기 | Jake가 호텔 앞 택시와 빌려주는 우산을 안내하고, 퀘스트의 **‘택시 부탁하기’**에 체크됩니다. |
| 호텔 로비 | 대화가 끝난 뒤 왼쪽 위 퀘스트 카드 확인 | 플레이어가 접은 우산을 들고 **‘2 / 3 택시로 햄버거 가게 가기’**로 넘어갑니다. |

`Excuse me, where is Maple Burger?`처럼 햄버거 가게 위치를 묻는 말도 같은 목표로 인정됩니다.

## 4. 택시로 Maple Burger 이동

| 화면 | 클릭·조작 | 확인할 결과 |
| --- | --- | --- |
| 호텔 로비 | 출입문으로 걸어 나감 | 비 오는 거리에서 플레이어가 우산을 펴 씁니다. |
| 호텔 앞 거리 | 차로의 택시에 다가가 **[택시 타기]** 클릭 또는 `E` | 뒷좌석 시점으로 바뀌고 기사 Joe가 목적지를 묻습니다. |
| 택시 대화창 | `Could you take me to Maple Burger, please?` 보내기 | 기사가 목적지를 확인하고 택시가 출발합니다. |
| 택시 이동 화면 | 대화를 열어 둔 채 하차할 때까지 기다림. 이동 중 `How long does it take?`라고 물어도 됩니다. | Maple Burger 앞에 내리면 **‘3 / 3 햄버거와 사이드 주문’**으로 넘어갑니다. |

이동 중 대화를 끝내 길가에 내렸다면 다음 단계로 가려면 택시에 다시 타고 **Maple Burger 앞 하차까지** 진행합니다.

## 5. Maple Burger에서 주문

| 화면 | 클릭·조작 | 확인할 결과 |
| --- | --- | --- |
| 가게 앞 보도 | **‘MAPLE BURGER’** 간판 아래 문으로 입장 | John이 주문 랩을 하면서 플레이어에게 걸어옵니다. |
| 가게 안 | John이 다가와 대화를 제안할 때까지 기다립니다. 제안이 뜨면 **[지금은 안 할래요]** 클릭 또는 `Esc` | John이 먼저 말을 거는 장면을 확인한 뒤 제안 창이 닫힙니다. |
| 가게 카운터 | **Rosa**를 클릭하고 **[대화하기]** 클릭 | Rosa가 단골로 알아보고 평소 주문인 크리스피 치킨 버거와 레모네이드를 제안할 수 있습니다. 초기 호감도는 **100**입니다. |
| Rosa 대화창 | `No, today I'd like a cheeseburger with no onions.` 보내기 | **‘치즈버거 주문하기’**, **‘재료 조건 말하기’**가 체크됩니다. |
| Rosa 대화창 | `And fries and a cola, please.` 보내기 | **‘사이드와 음료 주문하기’**가 체크됩니다. |
| Rosa 대화창 | `To go, please.` 보내기 | **‘매장 이용 여부 말하기’**가 체크됩니다. Rosa가 음식을 건네고 **7코인**이 차감되며 비가 그칩니다. 주문을 완료하면 시연 퀘스트가 끝납니다. |
| 가게 안 | 피드백 준비 안내가 뜨면 **[나중에 확인하기]** 클릭 | 대화 노트에서 주문을 확인할 수 있는 상태로 돌아옵니다. |

버거, 재료 조건, 사이드·음료, 매장·포장 여부는 한 문장으로 말하거나 여러 번 나눠 말할 수 있습니다. 왼쪽 위 체크리스트에서 남은 조건을 확인합니다.

## 6. 대화 피드백과 다시 연습

| 화면 | 클릭·조작 | 확인할 결과 |
| --- | --- | --- |
| 가게 안 | 피드백 완료 알림을 기다린 뒤 **오른쪽 위 파란 휴대폰 버튼** → **[대화 노트]** 클릭 | 방금 Rosa와 나눈 햄버거 주문 대화가 목록에 표시됩니다. |
| 대화 노트 | 주문 대화 줄의 **[피드백 보기]** 클릭 | 대화 피드백이 열립니다. |
| 피드백 화면 | 위쪽 **[요약] → [문장 교정] → [전체 대화]** 탭을 차례로 누름 | 잘한 점과 더 연습할 점, 교정 문장, 대화 내용을 볼 수 있습니다. |
| 피드백 화면 | 아래의 **[다시 연습]** 클릭 | 같은 상황의 새 주문 대화가 열립니다. 왼쪽 위 카드에 주문 조건이 표시됩니다. |
| 다시 연습 대화창 | **‘이번에 써 볼 표현’**을 참고해 다시 주문. 예시 `I'd like a cheeseburger with no onions, fries and a cola, to go, please.` | 말한 조건이 체크되고 추천 표현을 다시 써 볼 수 있습니다. |
| 다시 연습 대화창 | **[대화 종료]**를 클릭하고 **‘연습 돌아보기’**를 확인한 뒤 닫기 | 써 본 표현 수와 지난번·이번 문장을 확인하고 시연을 마칩니다. |

시연을 한 번 더 하려면 대화를 끝낸 뒤 **[퀘스트] → [이야기] → ‘비 오는 저녁, 햄버거 한 끼’ → [퀘스트 시작]**을 다시 누릅니다. 완료 후 다시 시작하면 시연 진행·시각·날씨가 출발 상태로 설정되며, 이미 저장한 대화와 피드백은 대화 노트에서 계속 볼 수 있습니다.

## 진행이 막혔을 때

| 상황 | 진행 방법 |
| --- | --- |
| 음성 처리 동의 또는 마이크 권한 화면이 뜸 | 음성 사용에 동의하고 브라우저에서 사이트의 마이크 권한을 허용합니다. 필요하면 같은 문장을 직접 입력합니다. |
| 말한 문장이 다르게 표시됨 | 입력칸에서 문장을 고친 뒤 **[보내기]**를 누르거나 **[말하기]**로 다시 녹음합니다. |
| NPC 클릭이 되지 않음 | NPC 쪽으로 몇 걸음 다가가 이름표나 몸을 눌러 봅니다. 열린 창이 있다면 `Esc`로 닫습니다. |
| 퀘스트 목표에 체크가 안 됨 | 왼쪽 위 목표와 현재 NPC를 확인합니다. **[힌트]**에서 추천 문장을 눌러 입력한 뒤 **[보내기]**를 누릅니다. |
| **[퀘스트 시작]**을 누를 수 없음 | 현재 대화를 종료하고 퀘스트 창을 다시 엽니다. |

NPC 답변은 대화마다 달라질 수 있습니다. 표의 영어는 진행 예시이며, 대화의 목표를 충족하는 표현으로 바꿔 말할 수 있습니다. [시연 퀘스트와 단계 기준](../docs/demo-rainy-evening.md#진행)
