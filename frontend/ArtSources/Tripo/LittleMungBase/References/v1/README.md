# Little Mung 기준 캐릭터 4뷰 이미지

사용자가 제공한 리틀 멍 이미지를 기준으로 만든 3D 제작용 2D 참고 시안이다.
머리카락 없는 머리, 눈썹·속눈썹·큰 눈·작은 코와 입, 대두 비율을 유지하고
회색 반팔 기본 티셔츠·반바지와 맨발, A포즈로 준비한다.
입은 작은 곡선의 편안한 기본 표정이며 감정·발음용 별도 모델 이미지가 아니다.

| 파일 | Unity Workbench 이미지 슬롯 | 방향 |
| --- | --- | --- |
| Front.png | 정면 | 얼굴과 몸이 카메라를 향함 |
| Left.png | 좌측면 | 캐릭터의 왼쪽 측면, 코가 이미지 왼쪽을 향함 |
| Right.png | 우측면 | 캐릭터의 오른쪽 측면, 코가 이미지 오른쪽을 향함 |
| Back.png | 후면 | 얼굴이 보이지 않는 뒷모습 |

위 4개만 각각 이미지 슬롯에 넣는다. 한 장짜리 합본 이미지는 쓰지 않는다.
IdentityReference.png는 원래 얼굴·비율을 비교하는 원본이며 Tripo 입력용 4뷰에 섞지 않는다.
prompts.json에는 내장 image_gen으로 사용한 최종 프롬프트를 보관한다.
원본의 정면을 참고해 측면·후면을 추정했으므로 실제 3D 모델에서 렌더한 정투영 결과는 아니다.
첫 3D 생성 전에 얼굴 인상과 두상·팔다리·옷 길이의 뷰별 일관성을 검토한다.

이 자료에는 Tripo 작업이나 3D 모델이 포함되지 않는다.
기준 모델 생성 뒤 공통 골격·가중치·얼굴 Shape Keys와 헤어·의상 착용 호환성을
Blender·Unity 작업대에서 별도로 준비·검수한다.
