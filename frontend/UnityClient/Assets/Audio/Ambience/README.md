# 서비스용 승인 음원

실외 반복음은 이전의 전면 실내 대화 레이어를 제외하고 거리 소음과 다른 영어 대화 레이어로 교체했습니다. 전체 루프는 약 46.5초이며 호명이 사라지고 영어가 더 들리는 두 번째 청음안을 사용합니다. 루프마다 되풀이되던 여자 웃음(22.3~23.7초, 24.85~25.4초)은 같은 대화 원본의 쓰지 않은 구간으로, 거리 소음의 높은 '꺄악'·끽 소리(25.7~26.45초, 27.85~28.1초)는 같은 거리 소음의 조용한 구간으로 바꿨습니다. 웅성거림과 거리 소음은 이어지고 그 소리만 들리지 않습니다. 변경한 파일의 측정값은 manifest의 해당 항목에 기록합니다.

사용자가 준비하고 승인한 반복 생활소음 9개와 단발 효과 5개의 OGG 사본입니다. 원본 WAV와 수집 파일은 사용자 다운로드 폴더에 보존합니다. 카페의 이름 호출 구간은 제외되어 있고 별도의 발자국·입장 효과나 대화 감쇠는 루프에 섞여 있지 않습니다.

연결과 가져오기 방법은 `Assets/Scripts/Ambience/README.md`를 따릅니다. 원본 `audio-manifest.json`의 파일 이름은 측정에 사용한 WAV 기준이며 각 OGG는 같은 이름의 서비스용 버전입니다. 기능 변경 없이 이 폴더의 음원만 교체하지 말고 반복 경계·음량·카탈로그를 함께 검수합니다.
