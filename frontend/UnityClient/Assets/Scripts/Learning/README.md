# Learning 모듈

단어장은 왼쪽의 단어 목록과 오른쪽의 선택 단어 상세로 나눕니다. 목록은 단어마다 옅은 흰 카드 한 줄(굵은 영어 단어, 그 아래 흐린 뜻)을 두는 스크롤 목록이며, 단어가 많으면 마우스 휠·끌기로 스크롤하고 넘칠 때만 목록 오른쪽에 가는 스크롤 막대가 보입니다. 목록 클릭과 목록 바로 아래의 화살표는 같은 선택 상태를 쓰며, 화살표로 고른 단어가 목록 밖이면 그 줄이 보일 만큼 스크롤합니다. 목록은 서버가 준 최근 저장순으로 보이고, 목록 바로 위 [최근순 | 알파벳순] 두 칸에서 순서를 고르며, 지금 순서는 목록에서 고른 줄과 같은 강조색 카드로 칠합니다. 알파벳순은 대소문자를 가리지 않습니다. 알파벳순일 때는 목록 맨 왼쪽에 A~Z를 두어, 누르면 그 글자로 시작하는 첫 단어를 고르고 그 묶음을 목록 맨 위로 올립니다. 그 글자로 시작하는 단어가 없으면 흐리게 두고 누를 수 없습니다. 상세에는 큰 단어 제목과 뜻(피드백 표현처럼 긴 문장이면 두 줄 안에 들 때까지 글자를 줄임, 목록 줄은 말줄임), 코랄 막대 제목으로 나눈 '예시 문장'(따뜻한 색 칸에 단어가 쓰인 문장과 문장 뜻)과 '메모'를 표시하고, 예시 문장이 없는 단어는 메모를 그 자리로 올립니다. 상세 영역 뒤에는 튜토리얼 말풍선과 같은 불투명한 흰 카드(`Art/UI/Theme/Jelly/Card.png`)를 깔아 뒤 장면이 비치지 않게 하고 왼쪽 목록과 구분합니다. 제목("단어장"·고른 단어)은 테마의 둥근 제목 글꼴을 쓰고, 나머지 글은 피드백 화면처럼 Pretendard로 씁니다(뜻은 굵게). 흐린 글자는 유리 판 위에서도 읽히도록 테마의 흐린 색보다 조금 진하게 둡니다. 저장한 건 단어이므로 문장 칸 제목은 '예시 문장'입니다. 사물 카드 예문·피드백 예문은 제목만 두고, 대화 중 NPC 대사에서 저장한 단어는 "예시 문장 · Ben이 한 말"처럼 어느 NPC가 한 말인지 붙입니다(이름 끝소리에 맞춰 이·가, `FeedbackText.NameAsSubject`). 고른 단어에 하는 [외웠어요]·[삭제]는 단어 제목 줄 오른쪽에, 메모 [저장]은 메모 입력칸 오른쪽에 둡니다. [외웠어요]를 누른 단어는 기록을 지우지 않고 목록에서 정리하며(기능 명세 F-35), 장소의 사물 카드도 그 단어를 숨긴 단어처럼 호버로는 띄우지 않습니다(사물을 클릭하면 보임). 외운 단어가 있으면 머리줄 X 왼쪽에 [외운 표현도 보기]를 둡니다. 켜면 외운 단어도 뜻 뒤에 "· 외웠어요"를 붙여 다시 보이고 [다시 학습]으로 되돌릴 수 있으며, 버튼은 [외운 표현 숨기기]로 바뀝니다. 단어장을 열 때마다 정리한 목록부터 보입니다. 모두 외워 목록이 비면 "모든 단어를 외웠어요"와 [외운 표현도 보기] 안내를 보입니다. 서버가 빈 목록을 돌려줬을 때만 "아직 저장한 단어가 없어요" 안내와 X를 보이고 편집 조작은 숨깁니다. 받기 전에는 같은 자리에 "단어장을 불러오는 중이에요…"만, 처음 읽기에 실패하면 "단어장을 불러오지 못했어요"와 [다시 시도]를 보입니다. 메모·외웠어요·삭제의 서버 저장 경로는 동일하며 서버가 성공한 뒤 표시를 갱신합니다.

화면 배치는 **Tools → A305 → UI → Apply Vocabulary Cards**로 적용합니다. 기존 `LearningBuilder`와 테마 Builder도 같은 배치를 사용하므로 다시 실행해도 예전 단어장으로 돌아가지 않습니다. 프리팹 두 개만 수정하며 공간 씬은 저장하지 않습니다.

대화가 끝나면 피드백을 보여 주고, 단어장 화면을 서버 단어장(VOCAB-01·02·03·04)과 잇습니다. 오른쪽 위 휴대폰 메뉴의 [피드백 목록] 앱은 지난 대화 목록에서 고른 대화의 저장된 피드백과 대화 기록을 같은 피드백 화면으로 다시 엽니다. 피드백은 [요약]·[문장 교정]·[회화 표현]·[저장할 표현] 탭으로 나뉩니다. 문장과 표현은 한 장씩 [이전]·[다음]으로 넘기며, 한 장보다 긴 설명도 내용을 자르지 않고 이어 넘깁니다. 서버가 이 상황에서 자주 쓰는 표현(`situation_expressions`)을 주면, 피드백을 열자마자 보이는 [요약] 위쪽 코랄 제목 "이 상황에서 자주 써요" 아래에 표현마다 흰 유리 칸(영어 표현, 자리가 있으면 같은 줄에 뜻, 쓰는 상황)과 카드 오른쪽에 [담기]를 두고(`FeedbackView`, `SituationRowLayout`), 그 아래 코랄 제목 "대화 요약" 밑의 따뜻한 색 칸에 요약 글을 둡니다. 모든 탭은 머리줄과 아래 버튼 줄 사이의 고정 영역을 세로로 스크롤합니다. 표현과 본문은 내용 높이만큼 차례로 쌓고, 영역 밖은 가립니다. 쪽 넘김은 숨깁니다. 잘한 점·아쉬운 점의 앞머리(잘했어요·아쉬워요)는 초록·코랄 굵은 글자입니다. [회화 표현] 탭도 같은 제목·같은 칸으로 그 표현을 보이고 예문을 한 줄 더 둡니다. [저장할 표현]과 [문장 교정]에서도 저장할 문장이 있으면 같은 디자인의 [담기]를 본문 카드 오른쪽에 둡니다. 저장할 곳이 없으면 버튼을 숨기며, 추천 표현 줄에 버튼이 있으면 별도 버튼을 중복 표시하지 않습니다. 본문 크기는 시안 기준 26, 영어 표현은 28, 뜻은 22, 쓰임과 예문은 20이며 실제 캔버스에는 1.2배로 적용합니다. 화면은 확정 시안대로 뒤가 비치는 유리 판에 머리줄(앱 아이콘·제목 "대화 피드백"·부제·탭·닫기)과 아래 줄([단어장]·[닫기])을 두며, 그림인 부분은 시안 HTML을 렌더링한 그림(`Art/UI/Feedback`)입니다. 판 안은 시안(1240×770)을 1.2배로 배치하고 화면에는 시안 크기로 줄여 보이되, 폭은 머리줄의 부제와 탭 사이가 남는 만큼 좁힌 1080입니다(`FeedbackView`). 위아래에는 화면 위 가운데의 튜토리얼 [건너뛰기] 카드 자리(150)를 남깁니다. 피드백·단어장·피드백 목록은 마을 HUD(퀘스트 카드·미니맵)를 함께 볼 수 있게 그 오른쪽 빈 곳 가운데에 놓이고, 들어가지 않으면 배율을 줄입니다(World 모듈의 `CenterWindow`, [Mission 모듈](../Mission/README.md)). 화면이 낮거나 좁으면 배치하는 판을 줄이고 본문 영역은 스크롤합니다. 배치는 **Tools → A305 → Learning → Apply Feedback Screen**(`FeedbackScreenBuilder`)이 만들고, 테마 Builder도 피드백 화면을 칠한 뒤 이 Builder를 부릅니다. 표현 줄 원본은 **Apply Feedback Situation Rows**(`FeedbackSituationBuilder`)로 프리팹에 더합니다. 단어장은 서버에 저장된 단어를 목록으로 보이고 '외웠어요' 표시, 메모, 삭제를 서버에 저장합니다.

이 서비스의 학습 흐름을 다루는 게임 전용 기능입니다. 지금 화면은 흐름 확인용 초안입니다. 서버 AI와 나눈 대화는 서버가 만든 피드백(CONV-08, FB-03)을, 튜토리얼처럼 대본으로 진행한 대화는 키워드 규칙으로 만든 예시를 보여 줍니다. 단어장 필터는 이후 작업에서 붙입니다. 사물 카드에서 저장(VOCAB-02 OBJECT)은 [ObjectHover 모듈](../ObjectHover/README.md#카드-버튼과-서버-연결)이 맡고, 단어장은 열 때마다 서버에서 다시 읽어 저장한 단어를 보여 줍니다. Editor에서 서버 단어장을 읽지 못하면 확인용 단어장으로 바꿔 같은 Play 동안 사물 카드에서 저장한 단어를 보입니다. 대화 중 [뜻]으로 받은 대사의 풀이 단어는 대화창 단어 카드의 [단어장에 저장]으로 그 턴 출처(VOCAB-02 NPC_LINE)로 저장합니다(화면은 [Dialogue 모듈](../Dialogue/README.md)). 피드백의 [담기]는 서버 대화 ID가 있으면 FEEDBACK 출처로 표현을 저장하며, 대본·예시 피드백에서는 숨깁니다.

## 구성

전체 대화의 NPC 말풍선에는 영어를 표시하고, 한국어 뜻은 말풍선 바로 아래 바깥에 둡니다. `TranscriptMeanings`는 턴별로 뜻 요청을 합치고 성공·실패 결과를 재사용합니다. 처음 전체 대화를 열 때 빠진 NPC 뜻만 CONV-04로 읽어 서버에 저장하며, 화면을 닫으면 다음 턴 요청을 중단합니다. 실패한 뜻은 원문을 유지하고 사용자가 다시 불러오기를 눌렀을 때만 재시도합니다. 대화가 바뀐 뒤 도착한 결과는 새 화면에 적용하지 않습니다. `FeedbackGlossaryHover`는 저장된 풀이가 있는 밑줄 단어·숙어를 PC에서는 호버, 모바일에서는 탭으로 보여 주며 AI를 호출하지 않습니다. 단어 풀이는 CONV-04의 최대 3개 범위를 따릅니다.

전체 대화에서는 사용자 말풍선 자체를 누르면 해당 문장의 피드백이 열립니다. 상세 화면은 낮고 밝은 코랄색 [전체 대화] 버튼과 '문장 피드백' 제목을 한 줄로 배치합니다. 돌아가기 버튼은 기존 피드백 탭의 그림을 재사용하며, 화살표는 왼쪽에, 이름은 버튼 가운데에 둡니다.

화면 정렬 순서는 오른쪽 위 휴대폰 메뉴(펼친 동안 1000)와 피드백 목록 창 95, 피드백 130, 단어장 135입니다. 피드백에서 [단어장 보기]를 누르면 단어장이 피드백 위에 열리고, 닫으면 피드백으로 돌아옵니다.

메뉴의 [내 정보]와 마이페이지 창도 이 HUD 프리팹에 있지만 동작은 [Onboarding 모듈의 마이페이지](../Onboarding/README.md#마이페이지)가 맡습니다.

하단의 [홈으로]는 모든 장소에서 기본으로 보이며 집(`HomeScene`)으로 바로 이동합니다. 이미 집에 있거나 대화·피드백·다른 이동 등으로 플레이어가 잠긴 동안에는 비활성화합니다. 서버의 퀘스트·기억·피드백 데이터를 초기화하지 않습니다.

피드백은 위쪽 X와 아래쪽 [닫기]로 어느 페이지에서든 닫습니다. 페이지 내용만 바뀌며 닫기·저장·단어장 버튼은 고정 영역에 남습니다. `FeedbackPagesPreview.Capture`는 고정 예시로 세 테마·세로 화면·긴 설명의 페이지 전환을 검사하며 외부 AI를 호출하지 않습니다.

`Assets/Data/Learning/MockFeedbackExamples.asset`의 규칙을 위에서부터 확인해 발화에 키워드가 모두 들어 있는 첫 규칙을 씁니다(`soy`+`latte`, `latte`, `coffee`, `dessert`, `straight`, `weather`). 필드 초기값은 에셋을 처음 만들 때 들어가는 예시이며, 이후 수정은 에셋에서 합니다.

## Builder

**Tools → A305 → Learning → Build**(`Scripts/Editor/Learning/LearningBuilder.cs`)가 `Prefabs/Learning/`의 `FeedbackScreen`·`VocabularyScreen`·`LearningHud` 프리팹과 확인용 규칙을 준비합니다. `LearningHud`에는 오른쪽 위 메뉴 버튼과 목록(`Panel/Menu`)을 만들고, 목록에 [단어장]·[피드백 목록]·[내 정보]·[조작법]·[홈]을 둡니다. 화면 디자인은 하나라 [테마]는 두지 않습니다. 테마 Builder가 버튼을 휴대폰 버튼으로, 목록을 삼성폰 메뉴로 바꾸고 [마을 지도] 앱을 더합니다. 피드백 목록 창(`History`)과 마이페이지 창, 오른쪽 아래 조작법 카드(`ControlsGuide`)도 만듭니다. 조작법 카드는 HUD 맨 뒤에 두어 메뉴 바깥 영역과 피드백 목록·내 정보 창이 그 위에 그려집니다. 휴대폰 버튼·폰 메뉴 모양은 테마 Builder(`UiThemeBuilder`·`PhoneMenuBuilder`)가 맞춥니다. 화면은 없는 요소만 만들고 이미 있는 요소의 디자인은 유지합니다. **Tools → A305 → Learning → Connect Vocabulary Server**는 단어장 프리팹의 메모·안내 요소를 맞추고 배포용 장소 씬 5개의 `LearningController`에 `ApiSettings`만 연결합니다. 공간 씬에 붙이는 일은 [World 모듈의 공간 기능 연결](../World/README.md#새-공간-씬-만들기)이 합니다.
