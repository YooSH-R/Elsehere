# Learning 모듈

단어장은 왼쪽의 네 항목과 오른쪽의 선택 단어 상세로 나눕니다. 목록 클릭과 하단 화살표는 같은 선택 상태를 쓰며, 경계를 넘으면 다음 묶음으로 이동합니다. 상세에는 뜻·저장한 문장(있는 경우)·메모를 표시합니다. 빈 목록에서는 안내와 X만 보이고 편집 조작은 숨깁니다. 메모·외웠어요·삭제의 서버 저장 경로는 동일하며 서버가 성공한 뒤 표시를 갱신합니다.

화면 배치는 **Tools → A305 → UI → Apply Vocabulary Cards**로 적용합니다. 기존 `LearningBuilder`와 테마 Builder도 같은 배치를 사용하므로 다시 실행해도 예전 단어장으로 돌아가지 않습니다. 프리팹 두 개만 수정하며 공간 씬은 저장하지 않습니다.

대화가 끝나면 피드백을 보여 주고, 단어장 화면을 서버 단어장(VOCAB-01·03·04)과 잇습니다. 오른쪽 위 메뉴(≡)의 [피드백 목록]은 지난 대화 목록에서 고른 대화의 저장된 피드백과 대화 기록을 같은 피드백 화면으로 다시 엽니다. 피드백은 [요약]·[문장 교정]·[회화 표현]·[저장할 표현] 탭으로 나뉩니다. 문장과 표현은 한 장씩 [이전]·[다음]으로 넘기며, 한 장보다 긴 설명도 내용을 자르지 않고 이어 넘깁니다. 서버가 이 상황에서 자주 쓰는 표현(`situation_expressions`)을 주면, 피드백을 열자마자 보이는 [요약] 위쪽에 표현마다 영어·뜻·쓰는 상황과 [담기]가 있는 한 줄을 모두 보이고(`FeedbackView`), 요약 글은 그 아래에서 시작합니다. [회화 표현] 탭은 그 표현과 예문을 한 장에 모아 보여 줍니다. 표현 줄은 **Tools → A305 → Learning → Apply Feedback Situation Rows**(`FeedbackSituationBuilder`)로 프리팹에 더합니다. 단어장은 서버에 저장된 단어를 목록으로 보이고 '외웠어요' 표시, 메모, 삭제를 서버에 저장합니다.

이 서비스의 학습 흐름을 다루는 게임 전용 기능입니다. 지금 화면은 흐름 확인용 초안입니다. 서버 AI와 나눈 대화는 서버가 만든 피드백(CONV-08, FB-03)을, 튜토리얼처럼 대본으로 진행한 대화는 키워드 규칙으로 만든 예시를 보여 줍니다. 단어장 필터는 이후 작업에서 붙입니다. 사물 카드에서 저장(VOCAB-02 OBJECT)은 [ObjectHover 모듈](../ObjectHover/README.md#카드-버튼과-서버-연결)이 맡고, 단어장은 열 때마다 서버에서 다시 읽어 저장한 단어를 보여 줍니다. Editor에서 서버 단어장을 읽지 못하면 확인용 단어장으로 바꿔 같은 Play 동안 사물 카드에서 저장한 단어를 보입니다. 대화·피드백의 [표현 저장]은 서버가 그 출처의 저장(NPC_LINE·FEEDBACK)을 열기 전까지 숨깁니다.

## 구성

| 파일 | 역할 |
| --- | --- |
| `VocabularyBook`, `VocabularyEntry` | 서버 단어장. 목록을 끝 페이지까지 읽고, 외웠어요·메모(200자까지)·삭제를 서버에 저장한 뒤 반영합니다. 실패하면 값을 그대로 두고 `LastFailureMessage`로 이유를 알립니다. Unity 객체 없이 테스트합니다. |
| `LocalVocabularyApi` | Editor에서 서버 단어장을 읽지 못했을 때 쓰는 확인용 단어장. 같은 Play 동안 확인용 단어 카드(`LocalObjectWordApi`)에서 저장한 단어를 최근 저장순으로 보이고, 외웠어요·메모·삭제도 같은 Play 동안만 기억합니다. 지우면 사물 카드에 [저장]이 다시 보입니다. 빌드에서는 쓰지 않습니다. Unity 객체 없이 테스트합니다. |
| `IVocabularyApi`, `VocabularyApi`, `VocabularyApiModels` | VOCAB-01·03·04 경로와 본문, 응답 형식. 외운 단어도 함께 읽습니다(`includeMemorized=true`). |
| `VocabularyListText` | 기존 문자 목록을 사용하는 호출자를 위한 포맷터입니다. 새 화면은 `VocabularyView`가 항목 선택과 상세를 따로 표시합니다. |
| `ConversationFeedback`, `UtteranceReview`, `ReferenceExpression`, `ReferenceRule` | 요약·상세 피드백. 서버 피드백은 요약·잘했어요·아쉬워요·개선 표현과 발화별 더 나은 표현·이유·회화 표현을 담고, 대본 대화는 발화마다 키워드 규칙의 참고 표현을 찾습니다. Unity 객체 없이 테스트합니다. |
| `FeedbackText` | 피드백 화면 본문 문구. 서버 피드백은 AI가 쓴 이유와 회화 표현을 그대로 보여 주고, "문법 오류를 매기지 않는다"는 안내는 키워드 규칙 예시에만 붙입니다. [대화 기록 보기]의 대화 기록도 만듭니다. Unity 객체 없이 테스트합니다. |
| `FeedbackExampleSource`, `MockFeedbackExampleSource` | 참고 표현 규칙을 찾는 곳과 서버 연동 전 확인용 규칙입니다. |
| `ConversationHistory`, `PastConversation` | [피드백 목록] 목록을 한 페이지씩 읽고(CONV-09), 고른 대화의 저장된 피드백(FB-01)과 대화 기록(CONV-10)을 피드백 화면에 보일 형식(`ServerFeedback`, 대사 목록)으로 바꿉니다. Unity 객체 없이 테스트합니다. |
| `IConversationHistoryApi`, `ConversationHistoryApi`, `ConversationHistoryModels` | CONV-09·10, FB-01 경로와 응답 형식 |
| `ConversationHistoryText` | 지난 대화 목록 문구(NPC·장소·시작 시각·피드백 상태). Unity 객체 없이 테스트합니다. |
| `LearningController` | 대화가 끝나면 피드백을 열고, 단어장을 열 때마다 서버에서 다시 읽고, 외웠어요·메모·삭제를 서버에 저장하고, [피드백 목록]에서 고른 대화의 피드백을 다시 열고, 화면이 열려 있는 동안 이동을 잠급니다. `apiSettings`가 비어 있으면 단어장과 피드백 목록을 열지 않습니다. |
| `FeedbackView`, `VocabularyView`, `ConversationHistoryView`, `LearningHudView` | 피드백 화면, 단어장 화면, 피드백 목록 창, 오른쪽 위 메뉴의 [단어장]·[피드백 목록]·[홈] 버튼과 저장 알림입니다. 피드백 목록 창은 HUD 프리팹에 있어 장소 씬마다 배치하지 않습니다. 피드백 목록·내 정보 창의 닫기는 단어장처럼 창 오른쪽 위 X입니다. |
| `HudMenu`, `HudMenuView` | 오른쪽 위 메뉴(≡)의 펼침 상태와 화면. 메뉴 버튼은 목록을 펼치고 접으며, 목록의 버튼을 누르거나 바깥을 누르면 접습니다. 펼친 동안 같은 자리에 강조한 메뉴 버튼을 보입니다. `HudMenu`는 Unity 객체 없이 테스트합니다. |

## 동작 규칙

| 상황 | 동작 |
| --- | --- |
| 내 발화가 있는 대화가 끝남 | 짧은 피드백을 열고 이동을 잠급니다. |
| 내 발화 없이 대화가 끝남 | 피드백을 만들지 않고 이동 잠금도 건드리지 않습니다. |
| 대화·피드백 [표현 저장] | 서버가 대화·피드백 출처의 저장을 열기 전까지 숨깁니다. |
| 단어장 열기 | 서버 단어장을 처음부터 다시 읽습니다. 읽는 동안 안내를 보이고, 실패하면 이전 목록과 이유를 보여 줍니다. Editor에서는 경고 로그를 남기고 확인용 단어장(`LocalVocabularyApi`)으로 바꿉니다. 장소에 들어올 때도 한 번 읽어 [단어장] 버튼 개수를 맞춥니다. |
| [외웠어요]·[다시 학습]·[삭제]·[메모 저장] | 서버에 저장한 뒤 화면을 다시 그립니다. 실패하면 값은 그대로이고 이유를 보여 줍니다. 메모는 200자까지 입력할 수 있습니다. |
| 서버 피드백 [문장 교정]·[회화 표현] | 발화 한 개씩 보여 줍니다. 고칠 표현이 없는 발화도 AI가 쓴 이유를 보존합니다. 회화 표현은 별도 탭에서 원문 맥락과 뜻을 함께 보여 줍니다. |
| 피드백 [저장할 표현] | 중복을 제외한 추천 표현을 한 개씩 보여 줍니다. 서버가 FEEDBACK 출처 저장을 지원하면 현재 카드의 영어와 뜻을 저장하는 버튼을 연결할 수 있습니다. |
| 피드백 [닫기] | 피드백을 닫고 `FeedbackClosed`로 NPC 키와 정해진 흐름 완료 여부를 알립니다. |
| 피드백을 받지 못함 | 제목으로 받지 못했음을 알리고, 평가 문구를 지어내지 않습니다. [표현 저장]·[상세 보기] 대신 [대화 기록 보기]로 방금 나눈 대화를 보여 줍니다(기능 명세 F-32). |
| 서버가 피드백을 만들지 못함(`FAILED`) | [다시 만들기]로 다시 만듭니다(FB-02). 기다리는 동안 버튼을 막고, 실패하면 이유를 보여 주며 다시 누를 수 있습니다. 종료 요청 자체가 실패해 서버에 피드백 기록이 없으면 [다시 만들기]를 보이지 않습니다. |
| 피드백을 만들지 않음(`SKIPPED`) | 제목을 "이번 대화는 피드백이 없어요"로 바꿉니다. |
| 대화 중 | [단어장]·[피드백 목록] 버튼이 꺼집니다. 두 화면의 이동 잠금이 대화의 이동 잠금을 풀지 않게 하기 위함입니다. |
| [피드백 목록] 열기 | 지난 대화 목록을 처음부터 다시 읽어 방금 끝낸 대화도 보입니다. 최근에 시작한 대화부터 NPC 이름·역할, 장소, 시작 시각, 피드백 상태(있음·만들지 못함·건너뜀·대화 중·없음)를 보여 줍니다. 저장된 결과만 읽어 AI 사용량이 소진돼도 열립니다. |
| [이전]·[다음] | 대화를 고릅니다. 받은 목록의 마지막에서 [다음]을 누르면 다음 페이지를 불러와 그 첫 대화를 고릅니다. |
| [피드백 보기] | 저장된 피드백과 대화 기록을 받아 대화 직후와 같은 피드백 화면을 피드백 목록 창 위에 엽니다. 만들지 못한 피드백은 [다시 만들기](FB-02)를 쓸 수 있고, 피드백을 만들기 전에 끝난 대화는 평가 없이 이유와 [대화 기록 보기]만 보여 줍니다. 닫으면 피드백 목록 창으로 돌아오며, 미션·튜토리얼에 대화 결과를 다시 알리지 않습니다. |
| 피드백 목록을 불러오지 못함 | 이전 목록은 그대로 두고 창 아래에 이유를 보여 줍니다. 다시 열거나 다시 누르면 다시 요청합니다. |

화면 정렬 순서는 오른쪽 위 메뉴와 피드백 목록 창 95, 피드백 130, 단어장 135입니다. 피드백에서 [단어장 보기]를 누르면 단어장이 피드백 위에 열리고, 닫으면 피드백으로 돌아옵니다.

메뉴의 [내 정보]와 마이페이지 창도 이 HUD 프리팹에 있지만 동작은 [Onboarding 모듈의 마이페이지](../Onboarding/README.md#마이페이지)가 맡습니다.

하단의 [홈으로]는 모든 장소에서 기본으로 보이며 집(`HomeScene`)으로 바로 이동합니다. 이미 집에 있거나 대화·피드백·다른 이동 등으로 플레이어가 잠긴 동안에는 비활성화합니다. 서버의 퀘스트·기억·피드백 데이터를 초기화하지 않습니다.

피드백은 위쪽 X와 아래쪽 [닫기]로 어느 페이지에서든 닫습니다. 페이지 내용만 바뀌며 닫기·저장·단어장 버튼은 고정 영역에 남습니다. `FeedbackPagesPreview.Capture`는 고정 예시로 세 테마·세로 화면·긴 설명의 페이지 전환을 검사하며 외부 AI를 호출하지 않습니다.

## 확인용 참고 표현

`Assets/Data/Learning/MockFeedbackExamples.asset`의 규칙을 위에서부터 확인해 발화에 키워드가 모두 들어 있는 첫 규칙을 씁니다(`soy`+`latte`, `latte`, `coffee`, `dessert`, `straight`, `weather`). 필드 초기값은 에셋을 처음 만들 때 들어가는 예시이며, 이후 수정은 에셋에서 합니다.

## Builder

**Tools → A305 → Learning → Build**(`Scripts/Editor/Learning/LearningBuilder.cs`)가 `Prefabs/Learning/`의 `FeedbackScreen`·`VocabularyScreen`·`LearningHud` 프리팹과 확인용 규칙을 준비합니다. `LearningHud`에는 오른쪽 위 메뉴(≡) 버튼과 목록(`Panel/Menu`)을 만들고, 목록에 [단어장]·[피드백 목록]·[내 정보]·[테마]·[홈]을 둡니다. [테마]는 꺼 두고 집 씬에서만 켭니다. 피드백 목록 창(`History`)과 마이페이지 창도 만듭니다. 메뉴 버튼·목록 줄 모양은 테마 Builder(`UiThemeBuilder`)가 맞춥니다. 화면은 없는 요소만 만들고 이미 있는 요소의 디자인은 유지합니다. **Tools → A305 → Learning → Connect Vocabulary Server**는 단어장 프리팹의 메모·안내 요소를 맞추고 배포용 장소 씬 5개의 `LearningController`에 `ApiSettings`만 연결합니다. 공간 씬에 붙이는 일은 [World 모듈의 공간 기능 연결](../World/README.md#새-공간-씬-만들기)이 합니다.
