# Tutorial 모듈

마을에 막 도착한 여행자가 숙소에서 걷기·둘러보기·사물 단어 저장·단어장을 익히고, 밖으로 나가 길을 헤매는 Ben에게 정해진 대사로 카페 가는 길을 알려 준 뒤, 피드백과 오늘의 목표(퀘스트 카드)를 확인하기까지 단계별로 안내합니다. 단계에 맞게 화면 위쪽 안내 카드와 코치 마크, 행인이 다가와도 되는지, 장소 이동·택시 잠금, 미션 표시를 바꿉니다.

이 서비스의 진행 흐름을 다루는 게임 전용 기능이며, 다른 기능 모듈의 공개 API만 써서 흐름을 잇습니다. 진행 단계는 Play 동안만 남고, Ben 길 안내 완료의 관계와 전체 완료·건너뛰기를 서버에 저장합니다.

## 서비스 UI와 기능 안내

설명 말풍선과 녹음 안내는 일반 서비스 카드·본문·알약 버튼의 테마를 따릅니다. 강조 표시는 대상 둘레에 맞춘 두꺼운 금색 테두리와 부드러운 광채를 사용하며, 광채가 사각형으로 잘리지 않게 여백을 둡니다. 대사 강조는 NPC 이름까지 포함합니다. `Tools → A305 → Tutorial → Apply Coach Mark Design`은 코치 마크 프리팹만 갱신하며 안내 문구와 장소 씬은 유지합니다.

Ben 대화의 첫 안내에서 일반 NPC 자유 대화의 호감도(인사·칭찬)와 무례한 말의 경고·종료 조건을 설명합니다. 튜토리얼을 마치기 전에 읽을 수 있으며, 정해진 Ben 대사 연습에서는 호감도가 실제 변하는 것처럼 표시하지 않습니다.

- 숙소가 아닌 장소에서 시작하면 숙소 안내를 건너뛰고 `MeetBen`부터 합니다.
- 이 브라우저에서 튜토리얼을 한 번이라도 끝냈으면(완료·[건너뛰기]) 새 계정(게스트 등)도 숙소 안내·Ben 대화 없이 시작하고, 서버에는 건너뛰기(TUT-02)로 저장합니다. 첫 퀘스트는 꼭 해야 하므로 이 브라우저에서 퀘스트 카드 안내를 확인한 적(오늘의 목표에서 퀘스트 카드를 누름)이 없으면 `TodayGoal`부터 시작해 그 안내만 보이고, 확인했으면 안내 없이 `Completed`로 시작합니다. Editor에서는 튜토리얼을 거듭 확인해야 하므로 이 기록을 쓰지 않습니다.
- [건너뛰기]는 카드 안에서 "튜토리얼을 건너뛸까요?"를 한 번 더 묻고, [건너뛰기]를 다시 눌러야 넘깁니다. 첫 퀘스트는 꼭 해야 하므로 건너뛰어도 `Completed` 대신 `TodayGoal`로 넘겨 퀘스트 카드를 누르는 안내는 남기고(`SkipToTodayGoal`), 이 안내에는 [건너뛰기]가 없습니다. 서버에는 이때 바로 건너뛰기(TUT-02)로 저장합니다. [계속하기]를 누르면 하던 단계로 돌아갑니다. Ben 제안·대화·대화 피드백·단어장·펼친 휴대폰이 할 일 카드를 가리는 동안에도 단계 이름과 [건너뛰기]만 남긴 작은 카드를 그 화면들과 코치 마크 덮개 위(정렬 순서 1100)에 두어 언제든 건너뛸 수 있습니다. 가운데 창(대화 피드백·단어장)은 이 카드를 `CenterWindow.TopObstruction`으로 받아 위아래에 카드 자리를 남기고 줄어 놓이므로 카드가 제목과 탭을 덮지 않습니다([World 모듈](../World/README.md), [Learning 모듈](../Learning/README.md)).
- 대화 제안·대화·피드백·단어장 화면이 떠 있으면 안내 카드를 숨기고, 그동안 할 일은 코치 마크 설명으로 알립니다. 카드는 이동을 막지 않습니다.
- Ben 대화는 글자로는 정해진 대사와 같게 입력해야 넘어갑니다(대소문자·문장부호·작은 오타는 허용). [말하기]로 말하면 무엇을 말했든 정해진 대사로 이어 가고, 다르게 들렸으면 그렇게 했다고 알립니다. 빈 입력칸에는 말하거나 입력할 대사가 회색 안내로 보입니다([Dialogue 모듈](../Dialogue/README.md)).

## 안내 카드

화면 위쪽 가운데에 짧은 카드 하나만 둡니다. 걷기·둘러보기의 할 일은 " · "로 나눠 적고, 해낸 것은 초록색으로 바뀌어 무엇이 남았는지 보입니다. 할 일 순서는 `TutorialProgress.RequiredActions`와 같아야 합니다(`TutorialGuideAssetTests`가 확인). 윗줄에 진행 점(●○)과 단계 이름·[건너뛰기], 가운데에 할 일 한 줄을 보이고, 주 버튼은 도착 인사의 [시작하기]에만 있습니다. 문구의 `{키}`는 강조색 `[키]`로 보입니다(테마 제목 글꼴에서는 TMP 강조 배경이 그려지지 않아 괄호와 글자색만 씁니다). 터치 조작판이 보이는 기기(휴대폰·터치 화면 노트북)에서는 단계별 터치 문구를 보입니다. 기호는 서비스 글꼴에 있는 ●·○·→·≡만 씁니다.

## 코치 마크

눌러야 할 버튼은 화면을 반투명 검은 판으로 덮고 그 버튼만 노란 테두리로 밝혀, 구멍 안만 누를 수 있게 합니다. 판은 밝힐 버튼이 있는 캔버스 바로 위에 그리므로, 그보다 위에 있는 안내 카드와 [튜토리얼 건너뛰기]는 가리지 않습니다. 걸어가야 할 숙소 문은 플레이어 발밑 바닥에 나침반처럼 옅은 노란 원을 깔고, 원 가장자리의 노란 점·화살표로 문 쪽을 가리킵니다. 문이 화면에 있든 없든 같은 자리에서 방향을 알리고 캐릭터를 가리지 않습니다(캐릭터 앞쪽을 가리킬 때는 캐릭터 뒤로 가려집니다). 1인칭처럼 발밑이 화면에 없으면 화면 아래 가운데에 카메라가 보는 쪽을 위로 한 화살표 배지를 띄워 돌아볼 방향을 알립니다. 다가오는 Ben은 머리 위에서 오르내리는 노란 화살표로 가리키되, 그 자리가 화면 밖이거나 위쪽 안내 카드 자리에 걸리면 얼굴을 가리지 않도록 띄우지 않습니다. Ben은 기다리는 구도에서 늘 화면 가운데로 다가옵니다. 안내 카드가 숨는 대화 제안·대화·단어장·피드백 화면에서는 할 일을 밝힌 곳 옆(오른쪽 → 왼쪽 → 위 → 아래 중 들어가는 곳)에 꼬리 달린 말풍선으로 알립니다. 옆에 두면 이웃한 버튼을 가리는 대상은 위나 아래를 먼저 씁니다(도구 줄·호감도·할 대사는 위, 대화 피드백 탭 설명은 오른쪽·자리가 없으면 아래, X는 아래). 호감도와 할 대사 설명은 가운데 서 있는 Ben 얼굴을 가리지 않게 밝힌 곳 왼쪽 끝에 맞춥니다(`captionAlignLeft`). 그때는 말풍선을 가장 넓게 펴 줄 수를 줄이고, 간격이 모자라면 화면 끝까지 붙여서라도 밝힌 곳을 덮지 않고 그 자리에 둡니다. Ben 대화를 시작하면 볼 곳을 하나씩 밝히는 티칭을 말풍선의 [다음]으로 넘기고, 티칭 뒤에는 대사 칸과 입력 줄을 테두리로만 함께 밝혀 대사를 읽을 수 있게 두고, 대사 칸 위 말풍선에 지금 할 대사와 뜻을 크게 보입니다. 녹음 중 불 설명은 설명 말풍선을 그대로 복사한 두 번째 말풍선([다음] 없음)으로, 불 오른쪽(대화창 바깥)에 남는 자리만큼 좁혀 꼬리로 불을 가리킵니다. 오른쪽 자리가 너무 좁으면(5:4 같은 화면) 불 위에 두며, 불 왼쪽의 [종료]·[보내기]·입력칸 위에는 두지 않습니다. 무엇을 밝힐지는 `TutorialCoachPlan`이 단계와 화면 상태로 고릅니다.

## Builder

**Tools → A305 → Tutorial → Build**(`Scripts/Editor/Tutorial/TutorialBuilder.cs`)가 `Prefabs/Tutorial/TutorialGuide.prefab`·`CoachMark.prefab`과 안내 문구 에셋을 준비합니다. 안내 문구는 없을 때만 만들고, 이후 수정은 에셋에서 합니다. 단계를 바꿔 문구를 코드 기본값으로 다시 맞춰야 할 때만 **Tools → A305 → Tutorial → Reset Guide Texts**를 씁니다. 공간 씬에 붙이고 씬에 놓인 행인 목록을 채우는 일은 [World 모듈의 공간 기능 연결](../World/README.md#새-공간-씬-만들기)이 합니다. 행인을 새로 놓았다면 연결 도구를 다시 실행합니다. 배포용 장소 씬 5개에 코치 마크와 단계 신호 화면만 다시 연결할 때는 **Tools → A305 → Tutorial → Connect Coach Marks**, `ApiSettings`만 다시 연결할 때는 **Tools → A305 → Tutorial → Connect Tutorial Saving**을 씁니다.

## 인사와 관계 형성

Ben은 자신을 소개하고 잠깐 질문해도 되는지 묻습니다. 사용자는 계정 닉네임으로 인사·소개하고, 직진 후 왼쪽으로 도는 길을 알려 주는 총 2턴을 연습합니다. 길을 알려 주면 Ben이 고맙다고 하며 길 안내를 마칩니다(첫 대사의 호감도 설명 뒤로는 설명할 것이 없어 대사를 줄였습니다). 닉네임을 아직 모르는 로컬 확인에서는 여행자로 소개합니다. [힌트]는 서비스와 같이 현재 대사를 추천 문장 카드에 펼치기만 하고, 펼친 문장을 눌러야 입력칸에 들어갑니다. 처음부터 자동으로 입력하지 않습니다.

인사를 보낸 뒤 이름 옆 호감도와 무례 경고를 밝히며 별도로 설명합니다. 연습의 긍정적인 응답마다 호감도 2씩, 총 4를 표시합니다. 실제 저장은 기존 TUT-03 완료 API가 담당하며 서버 기본 보상(+4)과 맞춥니다. 서버의 튜토리얼 보상 설정을 변경하면 이 연습 표시도 함께 맞춰야 합니다. 완료하면 인사·자기소개와 카페 길 안내 기억, 호감도·알아봄·방문 기록을 남기고 이후 자유 대화에 전달합니다. 재요청은 같은 만남을 중복 적립하지 않습니다. 무례한 말을 직접 시도하는 단계는 없으며, 자유 대화에서는 경고 한도에 이르면 NPC가 대화를 끝낸다고 안내합니다.

**Tools/A305/Dialogue/Apply Tutorial Ben Greeting**은 Ben 튜토리얼 대본만 현재 기본 흐름으로 갱신하고 미리 합성한 음성을 연결합니다. **Tools/A305/Tutorial/Align Service Guide Texts**는 휴대폰·저장 버튼·힌트·피드백 탭·관계 안내만 맞추며 다른 단계의 문구는 유지합니다.

하이라이트 검수는 `A305.EditorTools.Tutorial.TutorialHighlightPreview.Capture`에 `TUTORIAL_PREVIEW_OUTPUT` 출력 폴더를 지정해 실행합니다. 실제 숙소 프리팹의 일반 HUD·휴대폰·단어장 강조를 렌더링하며 씬 저장이나 서버 호출은 하지 않습니다.
